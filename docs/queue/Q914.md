# `git-merge-plan-index-test` calls every failed merge a conflict

`run_merge` runs `git merge >/dev/null 2>&1`, so any non-conflict failure reaches the assertion as `merge reported a conflict (rc=…)` with nothing to read.
Measured 2026-08-18: a conflict exits 1, a failed object write exits 2, so runs 32131116724 and 32131423171 on `main` (both `rc=128`) were neither and are undiagnosable.
Separate from [Q820](Q820.md), whose 128 is the suite aborting.
