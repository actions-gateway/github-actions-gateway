# The release gate asserts nothing about capacity or the quota rung

`validate-release.sh` has zero references to `capacityGate`, `nodeAutoscaling` or quota; its legs are deploy, e2e, sizing, CRD smoke. It builds an autoscaling cluster with headroom, so the constrained path is never driven on real infra.
