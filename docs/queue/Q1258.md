# Strip the Q147 legacy tenant-label dual-read once v1alpha1 is gone

No `actions-gateway.github.com` kind is served since Q273, so nothing should still accept that group's namespace labels as a tenant or privileged grant.
Q147 had the admission policies and the GMC read both namespace markers through the coexistence window, the legacy `actions-gateway.github.com/tenant=true` and `actions-gateway.github.com/privileged-profile=allowed` beside `actions-gateway.com/tenant=managed` and its v2 eligibility label.
[v2-ga.md](../plan/v2-ga.md#phase-3--the-storage-advance-and-the-coupled-removals) orders the strip after the served versions drop, and Q273 deliberately left it in place.

The legacy arms, measured 2026-11-01 with `git grep "actions-gateway.github.com/tenant\|actions-gateway.github.com/privileged-profile"`:

- `cmd/gmc/config/admission-policy/` `namespace-psa-guard.yaml`, `namespace-security-profile-guard.yaml` and `tenant-resource-guard.yaml`, with their chart twins under `charts/actions-gateway/templates/`, including the denial `messageExpression` text naming the legacy label.
- `isTenantNamespace` in `cmd/gmc/internal/controller/tenant_secret_access.go`, which binds the GMC's Secret reader into a namespace carrying either marker, and the `TenantNamespaceMarkerLabel` constant in `shared_reconcile.go` it reads.
- The e2e spec `E2E_Mirror_SharedTenantsNP` in `cmd/gmc/test/e2e/mirror_np_test.go`, which stamps the legacy marker on its unmarked control namespace to show the mirror's ingress peer does not admit it; once no policy reads that marker the stamp proves nothing.
- The chart README's upgrade note and `docs/operations/upgrade.md`, which tell an operator to apply the legacy label.

This is a security change in the narrowing direction: a namespace an operator marked only with the legacy label stops being a tenant namespace, so the GMC loses its Secret reader there and the guards deny its writes.
The operator docs have to say that before the tag, which makes the doc half [Q1107](Q1107.md)'s if it lands first.
