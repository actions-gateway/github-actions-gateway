# Run a Kata + Dragonfly e2e leg in the release gate

Blocked by Q1159's DinD leg ([PR #2031](https://github.com/actions-gateway/github-actions-gateway/pull/2031)) and by [Q539](Q539.md)'s back end ([PR #2027](https://github.com/actions-gateway/github-actions-gateway/pull/2027)).

Decided 2026-10-04: every release candidate is tested in each mirror mode, so the gate runs a third serial e2e leg after Kata and DinD, on Kata with `E2E_MIRROR_BACKEND=dragonfly`.
It is Kata rather than DinD because only the Kata tenant's egress is mirror-only; on DinD a worker reaches upstreams directly, so the back end is not the path under test.
Today `validate-release.sh` never sets either variable, so every gate run is Kata on Distribution alone.

**The shape is Q1159's.** `e2e-stop.sh`, then `e2e-start.sh` with the back end set, then `e2e_leg`'s dispatch, watch and report; a red matrix fails the gate.
Both legs rewrite the same sequence in `validate-release.sh`, which is why this waits for #2031 to merge rather than racing it.

**It adds the readings that make the leg say something about Dragonfly**, from [the plan's Phase 3](../plan/q539-dragonfly-mirror-backend.md#7-phases): blob `GET`s taking the P2P path in the seed peer's log, a worker timing out on the seed proxy port, and a `CONNECT` through the seed peer to `self-signed.badssl.com` refused.
A green matrix alone cannot tell the back end was used, because the mirrors serve either way.
The mirror census belongs on this leg as well as the plain Kata one.

**Cost.** One more leg per gate window; the runbook measures a healthy leg at 25–33 minutes, so three legs add roughly an hour over today's gate.
Node cost is unpriced, as it is for Q1159.
The CI path (`validate-candidate.yml`, Q880) already installs helm, which the back end needs to mint its CA.

The first gate run with this leg also discharges Q539's Phase 3, so Q539 closes when it does.
Not [Q1025](Q1025.md), which is about driving the admission ladder's placeability rung in the same script; this adds a leg rather than a reading to an existing one.
