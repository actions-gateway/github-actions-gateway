# Gate every hand-kept table of contents against its own headings

Q865 gated one page, because widening it was a larger change than that row held.
Measured 2026-08-18 by running [`check-upgrade-toc.sh`](../../scripts/docs/check-upgrade-toc.sh) over each of the 20 pages carrying a `## Table of Contents`: 16 have headings their own index never mentions, six of them operator-facing — `troubleshooting.md` 17, `security-operations.md` 16, `kata-dind-workloads.md` 3, `resourcequota-sizing.md` 2, `backup-restore.md` and `velero-backup-restore.md` 1 each.
The counts are the checker's level-2-and-3 rule, not each page's own: `troubleshooting.md` indexes level 2 alone, so seven of its 17 are that convention rather than drift.
So the mechanism is measured and the per-page figure is not — deciding the eligible depth per page is most of this item's work.
The checker is page-agnostic already; the change is where the depth rule comes from and how the gate selects files.
