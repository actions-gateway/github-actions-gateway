# v2 envtest twins for behaviours only the deleted v1 suites covered

The GMC half of Q273 deleted the suite files holding 58 envtest functions that drove the v1 `ActionsGateway` reconciler, and a name-level comparison against the remaining `v2_*` suites finds no twin for the behaviours below.
That comparison is the whole measurement: each item is a candidate, so read the named v2 suites for an assertion that already covers it before writing one.
The deletion removed no v2 coverage, since the two reconcilers never shared these paths; the gaps were there before, and the v1 suites were standing in for them.

Highest first, because the first is a tenant-isolation property:

- **The AGC's RBAC scope, enforced.** v1 had `TestGMC_AGCRBACScopeEnforcement_CrossNamespaceDenied`, `TestGMC_AGCRoleBinding_PermitsOwnNamespace` and `TestGMC_AGCRole_ReadsWorkerServiceAccountOnly`, which impersonate the AGC ServiceAccount and assert what the API server allows.
  `TestV2_ActionsGateway_ProvisionsAGCControlPlane` asserts the RoleBinding exists, which is not the same claim.
- **No steady-state churn** (`TestGMC_ApplyHelpers_NoSteadyStateChurn`): a reconcile of an unchanged gateway writes nothing.
  `TestV2_GMCRestart_LeavesTheAGCDeploymentUntouched` covers one object across a restart.
- **Credential rotation** (`TestGMC_CredRotation_PodTemplateAnnotation`, `_InPlaceUpdateNoRollout`): a changed Secret reference rolls the AGC through the pod-template annotation, and an in-place Secret edit does not.
  `docs/getting-started.md` documents both.
  The delete half is covered by `TestGMC_TenantSecretAccess_ScopesReadsToTenantNamespaces`.
- **Proxy and metrics certificate renewal** (`TestGMC_ProxyCert_*`, `TestGMC_MetricsCert_*`): renewed near expiry, left alone while valid.
- **Degraded on a provisioning error** (`TestGMC_Degraded_OnProvisioningError`), covered for v2 only by the unit tier.
- **HPA bounds follow a spec change** (`TestGMC_HPABoundsUpdate`, `_MinReplicasClamped`); the v2 HPA tests cover scale-out preservation and the floor.
- **An AGC log-level change rolls the AGC** (`TestGMC_LogLevelChange_RollsAGCAndProxy`); `TestV2_EgressProxy_LogLevelChange_RollsProxy` is the proxy half.
- **Egress NetworkPolicy refresh on a proxied pool, and `managed: false`** (`TestGMC_NetworkPolicy_IPRangeReconciler_UpdatesExistingPolicy`, `_ManagedFalse_NoGitHubCIDRs`); `TestV2_DirectEgress_IPRangeRefreshUpdatesDirectPolicies` is the direct-egress half.
- **Teardown removes only owned objects, and a re-apply after delete provisions again** (`TestGMC_TenantTeardown_*`), beside `TestV2_Teardown_FailClosedUntilChildrenGone`.
- **No ResourceQuota is created** (`TestGMC_TenantProvisioning_NoResourceQuotaCreated`), the least-privilege property `docs/design/05-security.md` states.

The deleted functions are readable at the parent of the Q273 GMC-half commit, under `cmd/gmc/internal/controller/integration/`.

The AGC half deleted the `RunnerGroup` envtests in `cmd/agc/internal/controller/integration/`, readable at the parent of its commit.
Most were classic-only, which Q264 retires, or already had a `TestV2_RunnerSet_*` twin, and four that had neither were ported first (`WorkersUnschedulable_NotTrippedForPlainPending`, `WorkerPodEventTriggersReconcile`, `ScaleSet_TemplateEditTakesEffectWithoutRestart`, `ScaleSet_PriorityTiers`).
These left with no envtest twin, each pinned at the unit tier only:

- **The worker pod's enforced invariants on a real apiserver** (`TestAGC_PodProvisioning_CorrectSpec`): `automountServiceAccountToken: false`, the worker ServiceAccount, the proxy env and the security-profile defaults; `TestProvisioner_ReservedFieldsOverwritten` covers the overwrite on a fake client.
- **The reaper's TTL and Pending-deadline arms driven by the real Pod watch and `RequeueAfter` timer** (`TestAGC_Reaper_CompletedPodDeletedAfterTTL`, `_StuckPendingPodDeletedAfterDeadline`); `TestReaper_ReapsExpiredWorkerPods` covers the arithmetic.
- **A worker pod name at the 63-character DNS-label boundary admitted by the apiserver** (`TestAGC_Q467_WorkerPodNameAtTheDNSLabelBoundary`); the naming unit tests cover the truncation.
- **A crashed worker leaving no job Secret behind** (`TestAGC_FailureRecovery_PodCrash_NoSecretLeak`); `TestV2_RunnerSet_ScaleSet_ReclaimsJobSecretOnCompletion` covers the completed case.

The unit tier has the same shape.
The GMC half ported the deleted unit tests whose subject v2 still calls (the shared builders, `evalProxyPoolQuota`, `footprintFromResources`, `refreshStalledMessage`), and left these, where v1 had its own implementation and the v2 one has no direct test (`git grep -l -w <name> -- cmd/gmc/internal` lists no `_test.go` file for each, measured 2026-11-02):

- `NamespacePSAReconciler.applyNamespacePSA`: an apply conflict retries with `ForceOwnership`, which is the expected path on a 1.x upgrade because the 1.x field manager owns the PSA keys; `Forbidden` and other errors propagate without the retry.
- `EgressProxyReconciler.ensureProxyCert`: a valid certificate is left alone, and one near expiry or unparseable is reissued.
- `EgressProxyReconciler.applyHPA` and `applyPDB`: a spec change on an existing object is patched.
- `patchDirectEgressNetworkPolicies` and the IP-range reconciler: a refresh keeps the workload policy's proxy egress rule, and an unmanaged pool is skipped.
