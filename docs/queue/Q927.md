# cosign has no updatecli manifest, so its pin only moves by hand

kind, polaris, shellcheck and syft each have one; cosign does not, so the binary that signs and verifies every release is the one pin nothing keeps fresh.
Q903's gate holds the copies to each other, which is a different property: three sites agreeing on a stale version still agree.
The pattern the other four use does not transfer unchanged, because cosign's pin is four per-platform digests in a shell `case` block rather than one `SHA256:` field, so a manifest has to rewrite the block and resolve four digests — all four now asserted by [download-cosign-test.sh](../../scripts/release/download-cosign-test.sh).
