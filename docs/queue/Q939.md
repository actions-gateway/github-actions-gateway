# `md-reflow-coverage` counts the excluded generated doc through a symlink

`excluded()` drops `docs/development/broker-compatibility.md`, but `git ls-files '*.md'` also yields `cmd/probe/compat/testdata/broker-compatibility.md`, a symlink to it added 2026-08-18 by Q895.
The formatter refuses that path outright (`refused: not a regular file (symlink)`), so the script measures a file mdreflow never walks and books its 18 lines as permanent residue: 18 of the 62 reported on 2026-08-18, with the same file's interior breaks inflating the denominator.
The script's own header names this failure mode.
`check-em-dash.sh` and `check-doc-links.sh` already drop symlinks from the same walk; do the same here.
Then re-take the figures in [documentation-standards.md](../development/documentation-standards.md#what-stays-hard-wrapped-and-why-it-stays-that-way), which still hold a v0.1.7 reading the pin moved past on 2026-08-15.
