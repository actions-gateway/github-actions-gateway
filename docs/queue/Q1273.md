# Retire the AGC's classic-only metrics, Admit chain and eviction budget

Q264 removed classic acquisition from the AGC and left the code and series only the classic path wrote.
Unlike [Q1272](Q1272.md), this reaches operators: shipped alerts and dashboards query series no AGC exports any more, so they can never fire or draw, and nothing says so.

**Dead series, measured 2026-11-02 on the Q264 branch.** Twelve `runnercore.Metrics` fields have no writer outside tests, found by scanning `cmd/agc` for `.<Field>` and then for writes inside `metrics.go` itself (which is how `MessagePollErrorsTotal`, written by the `PollErrors` recorder, and the token-refresh pair, set at `main.go:354`, turned out live):
`jobs_acquired_total`, `job_acquisition_errors_total`, `jobs_admission_rejected_total`, `jobs_duplicate_delivery_total`, `abandoned_delivery_completions_total`, `fanout_loser_recycle_deferred_total`, `renew_job_errors_total`, `renew_job_teardowns_total`, `agent_recycles_total`, `agent_recycle_errors_total`, `broker_token_propagation_retries_total` and `broker_session_leaks_total`, each `actions_gateway_`-prefixed.
`deploy/monitoring/prometheusrule.yaml` names them on 10 lines, in alerts including `ActionsGatewayRenewJobErrors`, `ActionsGatewayAgentRecycleErrors`, `ActionsGatewayAbandonedDeliveryErrors` and `ActionsGatewayCapacityGateRejectingJobs`; the three Grafana dashboards, `deploy/monitoring/preview/exporter.py`, and seven `docs/operations/` pages name them too (`git grep -l` over `deploy docs/operations`).
`upgrade.md` is among those pages, so an operator upgrading to `v2.0.0` needs telling which alerts went quiet.

**Dead code.** `Provisioner.Admit` and the `runnercore.AdmitFunc` type it feeds (`hooks.go` says the classic listener is its only caller), the `AdmitReason*` constants behind `jobs_admission_rejected_total`, and `handleEviction`'s classic branch: the in-process `evictionCounts` budget chosen when `tier` is not `evictionTierScaleSet`, with about 20 tests in `eviction_internal_test.go` and `abandoned_rerun_internal_test.go` that pass `evictionTierClassic`.
Dropping the classic tier also leaves the eviction metrics' `tier` label one-valued; whether to keep it for query compatibility or drop it is this row's call, and it is operator-visible either way.

**Comment narration.** About 280 comment lines across 55 AGC files still mention the classic tier (`git grep -c -i -w -E 'classic|AcquireJob' -- 'cmd/agc/*.go'`, excluding `vendor` and `test/load`).
Q264 fixed the ones that stated something false; most of the rest compare the scale-set path against code that no longer exists ("identical to the classic path", "classic parity"), which the comment standard's no-history rule rules out.
`listener.go`, `metrics.go`, `runnerset_scaleset.go`, `provisioner.go` and `eviction_scaleset.go` hold the most.
