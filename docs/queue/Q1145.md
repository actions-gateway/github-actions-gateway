# check-release-ladder-test revived-missing flakes under make check

Sighted once, 2026-09-29, in `make check` on the Q737 branch, whose diff touches neither the checker nor its test:

```text
[check-release-ladder-test] FAIL: revived-missing — a revived item whose row is gone fails: expected rc 1, got 2
[check-release-ladder-test]        release-ladder:  does not exist, so this gate would verify nothing
```

The double space is the finding: the checker was handed an empty page path, so `$(write_page rm …)` at `scripts/docs/check-release-ladder-test.sh:113:"$(write_page rm "$TWO_ROWS" three "$BACK")" \` produced no output that run.
The same test passed 3/3 run alone on the same tree minutes later, and every other case in the failing run passed.

**Mechanism unverified.** Nothing measured says why `write_page` printed nothing.
The fixture directory is `tmp/release-ladder-test.$$`, so a second concurrent instance should not share it; a failed write inside the substitution under `inherit_errexit` would produce exactly this empty path, but no failed write was observed.
Start by reproducing under load (the test beside `make scripts-test`'s parallel siblings) before choosing a fix.
