# The queue-lint citation remedy is wrong, and its advice degrades rows

[maintaining-backlog.md](../development/maintaining-backlog.md) says of the `queue-lint` citation note that only moving the number out of the pattern works, and recommends writing "at line 457 of" followed by a Markdown link to the file rather than linking the `file:line` string itself.

Both halves are wrong, and the recommended remedy discards something the store is built on.

**Rooting the path clears the note with the number left in place.** `scripts/docs/queue.py:553:            if any((base / path).exists() for base in (store.parent, store.parent.parent)):` skips the note whenever the cited path resolves from `docs/` or the repo root.
The note fires on an unresolvable *path*, never on the presence of a number, so the fix is to root the citation rather than to dismantle it.

**Measured 2026-09-09 (Q1078).** Q1089 was filed citing the eviction test by bare filename and reported the note twice.
Re-pointing to `cmd/agc/internal/provisioner/eviction_internal_test.go:274` cleared both, with the pattern still matching and the line number still in the text.
The linter's own message offers this first ("re-point or drop it"), so the doc contradicts the tool it documents.

**The recommended prose form loses the addressability the store wants.** [`docs/queue/README.md`](../queue/README.md) and the `session-backlog` skill both carry a citation as path, line and fragment, so a reader on a different tree finds the line by its text once the number has drifted.
Moving the number outside any pattern is what stops the note firing, and it is the same property that stops a drift check or a recount finding it.

**The doc generalised from the one case where its remedy was the only one available.** The original finding is sound and worth keeping: a Markdown link does not help, because the pattern matches inside the label.
What does not follow is "only".
Correct that sentence, keep the link-does-not-help finding, and add that the note is a warning at exit 0 rather than a gate failure, since the message goes to stderr and is never appended to `problems`.

**The class is live in the store.** `make queue-lint` on 2026-09-09 also reported Q1084 citing `local-throttle.sh` by bare filename, so this is not a one-row curiosity.
