# Let pin-bearing docs cite a third-party version

`check-release-pins.sh` reads every bare `X.Y.Z` in its five pin files as a GAG pin, so `README.md` cannot name the ARC version a measurement used. The [pre-flight](../operations/release.md#1-pre-flight) asks for that re-measurement every release.
