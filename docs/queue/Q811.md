# Graceful-deletion recovery cannot see a cancel, so a hand-deleted worker re-runs a cancelled run

`externallyDeletedBeforeTerminal` cannot see a cancel: the runbook's delete supplies the mark, and a `cancelled` conclusion accepts `rerun-failed-jobs` (measured 2026-08-05). Both tiers take it.
