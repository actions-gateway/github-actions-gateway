# metric-reference-check does not read the reference's rows

An operator copies a query from the [metrics reference](../operations/observability-metrics.md), so a label the reference lists and the AGC does not write gives them a query that returns nothing and raises no error.
`make metric-reference-check` cannot catch that, because it never reads a row: `checkReference` in `main.go` passes a metric whose backticked name appears anywhere on the page, and the label-value check holds values to `Help`.

**Measured 2026-11-06 at the head that closed Q1291**, running `scripts/docs/check-metric-reference.sh cmd/agc <doc>` over edited copies of the reference:

| Copy | Exit |
|---|---|
| `eviction_retries_total` row lists `namespace`, `runner_group`, `tier`, `bogus` | 0 |
| Both rows opening with `eviction_retries_total` removed, 2 mentions left in other rows' prose | 0 |
| Those rows removed and every other mention renamed, as the control | 1, `has no entry` |

Q1291 met the same gap by hand: the gate stayed green while the reference still listed the removed `tier` on all seven rows.

**The column is accurate today, as far as a one-off scan reaches.** A regex comparison of `cmd/agc` definitions against the reference's rows compared 36 metrics, and all agree except `worker_usage_cpu_peak_cores`, which is the scan's own miss: `internal/usage/metrics.go` passes its labels as the variable `setContainer`, and the reference is right.
All 42 `Name:` literals in `cmd/agc` also have a row opening with their name.
So this row adds a check and fixes no known wrong entry.

**What the fix has to handle.** `constructorArgs` already collects each metric's label names, but only from a `[]string` literal, so a list held in a variable reads as no labels.
The check has to resolve that form or report it, or those metrics would read as mismatched or go unchecked.
It also has to parse the reference's label cells, and a metric's row may appear more than once on the page, as the older *Breaking observability changes* tables do with a different column shape.

**Done when** `make metric-reference-check` fails a metric with no row of its own and a row whose labels differ from the definition's, with `main_test.go` covering a metric named only in prose, a wrong label, a missing label and a list held in a variable.
Both failures come from the one change, reading the rows.
