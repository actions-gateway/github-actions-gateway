# Validate RWX persistent storage for worker jobs, and put it in the reference architecture

Workers are storage-less and nothing validates a `ReadWriteMany` volume mounted into one. RWX is how jobs share files, and what ARC's `containerMode: kubernetes` needs, so it is also a migration blocker. **Unblocks [Q727](Q727.md).**
