# Five instruments measured returning a clean result that meant nothing

One batch, five: a non-fence-aware heading regex; `gh run list --commit` empty on queue-merged commits (runs attach to the merge_group ref); `git diff HEAD..origin/main` reporting both directions; cwd drift making a path-scoped `git diff` read clean; `grep -c` counting passing lines.
Each escape is known; the set is not written down.
