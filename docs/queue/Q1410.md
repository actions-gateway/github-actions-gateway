# Consider moving the OOM reporter to its own repository

**This reopens Q1403's D5, which on 2026-11-24 put the OOM reporter in this repository, as its own module, image and chart, over a repository of its own.** D5's table already weighs both reasons to move: the reporter is useful without the gateway, and here it runs on the gateway's cadence.
What the question now turns on is the cadence row.
The reporter is expected to change far less often than the gateway, yet every gateway release builds, scans, signs and publishes its image (`publish.yml`'s matrix and notes loop name `oomreporter` beside the seven gateway images), so an unchanged reporter is re-released with each one.

**Moving stays cheap while nothing imports across.** Measured 2026-11-25 on `4cbe33286`: `cmd/oomreporter` is its own Go module, and none of its Go files imports another module of this repository.
The only tie runs the other way: the AGC reads the pod condition the reporter writes, by the `oom.actions-gateway.com/` prefix and the reason names in `cmd/agc/internal/provisioner/oom_reason.go`, which take them from `cmd/oomreporter/internal/controller/words.go`.
D5 planned a gate that fails if either side imports the other, and Q1403's PR 3 (#2428) adds it as `scripts/go/check-oomreporter-imports.sh`, which keeps the move a move rather than an untangling.

**What a move costs**, from D5's table and since: the whole release pipeline again (builds, signing, SBOMs, scans, verification, a release process), its own docs and CI, including the kind e2e lane Q1403's PR 5 adds, and the condition becoming an interface between two repositories, versioned and documented as one, where a change to it is today one PR that both sides' tests read.
Q1403 gates 2.1 on the reporter, so 2.1 would then depend on another repository's release.

**Ask:** keep D5, move the reporter once Q1403's PRs have landed, or move it later with the import gate and the condition held stable meanwhile.
The call is the maintainer's, since it creates a repository outside this one.
Whichever is picked, the reporter's own docs should say it runs without the gateway.
