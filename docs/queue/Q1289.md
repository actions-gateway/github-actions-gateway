# E2E_V2_PerGatewayJobIsolation can pass in under a second

During the Q1167 work on 2026-11-04, `E2E_V2_PerGatewayJobIsolation` passed in 0.09 s, because the pod list was already non-empty 47 ms after the job was enqueued.
Measured once, on a reused private kind cluster; a passing spec prints no timing, so how often it happens is unknown.
The cause is unmeasured, and fakegithub state left on the reused cluster is only a guess.

`assertGatewayJobYieldsScopedWorker` accepts any existing pod for the set, so a pod that predates the enqueue can satisfy it, and the spec then passes without showing that this job was handled by this gateway's AGC, which is the isolation it is named for.
Fix by making the assertion name the enqueued job rather than any pod.
