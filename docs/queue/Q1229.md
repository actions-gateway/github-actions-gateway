# Plot proxy CONNECT outcomes by allowlist entry on a dashboard

`actions_gateway_proxy_connects_total{destination,outcome}` (Q1178) counts every CONNECT by the allowlist entry that admitted it and how it ended, but no shipped dashboard plots it, so an operator has to write the query by hand to see which destination is failing.
Q1178 left the panel out because a dashboard change needs a fresh screenshot from the kind-backed preview harness (`make dashboard-render-check` fails without one), which was out of proportion to that row.
The tenant dashboard's Egress Proxy row is full at 24 columns (five panels, read from `deploy/monitoring/grafana-dashboard-tenant.json`, 2026-10-27), so a panel there needs a second line in that row and shifts every row below it; the security dashboard's Abuse Signals row is the other candidate.
The query the operator docs give is `sum by (destination, outcome) (rate(actions_gateway_proxy_connects_total{outcome!="tunneled"}[5m]))`.
Done means the panel ships in the dashboard JSON, `deploy/monitoring/preview/exporter.py` emits the series so the preview populates it, the screenshot in `docs/assets/` is re-rendered, and `docs/operations/observability-dashboards.md` lists the panel.
