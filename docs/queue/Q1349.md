# testing.md probe table breaks after Investigation F, G-J render as prose

The credential-gated probe scenarios table in [testing.md](../development/testing.md#the-credential-gated-probe-scenarios) ends after the Investigation F row, because a blank line follows it.
Rows G through J then render as one paragraph of pipe characters on the published page, and `mdreflow` treats them as prose, joining each row onto the previous one's line and splitting it at sentence ends (seen 2026-11-12 when adding the Investigation J row).
Read from the source and the reflow output, not from a rendered page.

The likely fix is to delete the blank line and put each of G to J back on one line; whether `mdreflow --check` then accepts multi-sentence cells is unmeasured.
