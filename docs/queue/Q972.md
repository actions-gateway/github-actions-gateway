# Refund the scale-up token when a deduped listener loses the race

`Admit` takes a `spec.scaleUp` token before the claim (Q717), and the Q260 dedup loser returns from `listener/job.go` without ever creating a pod, so N fanned-out siblings spend N tokens for one worker: the ramp becomes `maxPerSecond/N` under exactly the burst the knob smooths.
That path already frees its ceiling reservation early and explicitly; the token has the identical argument and no mechanism.
A refund needs a way to tell an early abort from a completion, which the idempotent release closure cannot express, so this is a design decision rather than a patch.
Measured in review of #1702.
