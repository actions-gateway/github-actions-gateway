# Nothing keeps the shell egress banner in step with the Go one

The runner-host GitHub egress verdict is implemented twice, and only one copy is tested.
`cmd/gmc/test/utils.GitHubEgressGuidance` is a pure function with a table test; the `Collect diagnostic info on failure` step in `e2e-reusable.yml` re-implements the same decision in a `case` over `$gh_code`, and no test drives it.
What holds them together is a godoc sentence saying to change both together.

## Why the untested copy is the one that matters

The shell mirror exists precisely for the case where the suite process died before its `AfterEach` could run.
So when the two disagree, the shell copy is the only banner in the log, and its wrong advice is the whole of what the operator reads.
The Go copy's test cannot see that.

## The class has already cost something here

Q1126 shipped the layer caveat into both copies: an HTTP refusal arrives over a completed TCP connection, so it is evidence against a dial-level cause rather than for one.
The Go side now has a test that fails if the two `BLOCKED` arms collapse back into one, and the shell side has the same sentences with nothing asserting they stay.
A future edit to either can drift the pair silently, which is the state Q1126 was filed out of.

## Two candidates, neither settled

- **Extend the workflow-step harness.** `scripts/ci/workflow-step-body.sh` already extracts a step's body and `workflow-acting-steps-test.sh` drives one with stubs on `PATH`.
  Its header derives its subject deliberately as the steps that **act** rather than report, on proportionality grounds, and this step reports.
  So adopting it here means widening that derivation, and the argument for widening is that a reporting step's decision was wrong and cost a triage.
  Note the step runs under `set +e` and dumps a dozen `kubectl` commands, so a case needs stubs for all of them.
- **Assert the text instead.** A gate that requires the distinctive sentences of each `GitHubEgressGuidance` arm to appear in the workflow's matching arm is far smaller than driving the body, and catches drift rather than behaviour.
  It buys less and costs a fraction; whether that trade is right is the question this row is for.
