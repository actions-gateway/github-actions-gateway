# Retry classified platform failures, starting with OOM under right-sizing

Q555's detection measures each class's retry success rate (R14) in `actions_gateway_eviction_rerun_outcomes_total`, keyed by `cause`; the budget a class spends survives a restart (`rerun_ledger.go`).
Phase 2 of [the draft](../plan/q555-flaky-job-retry.md#classified-platform-retry-phase-2), split out of Q555 so that row stays detection: a framework for failure classes GAG recognises as platform-caused, each declaring how its cause clears (a fresh pod, state GAG can watch, or backoff with a breaker), on the existing re-run arms and budget.
The first class is `OOMKilled` under a `Throughput` or `Binpack` sizing profile, retried only when the next attempt gets a strictly higher memory limit, computed from the killed pod's own limit rather than the set's history ([why](../plan/q555-flaky-job-retry.md#oomkilled-under-right-sizing)).
The other candidates in the draft's table each need a dogfood reproduction before they become classes.
