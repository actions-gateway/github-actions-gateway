# A renamed or deleted set's scale set is adopted by the next tenant

When a set's first label is renamed, or a `RunnerSet` is deleted, the old scale set stays registered at GitHub, and the next tenant admitted onto that name adopts it by exact name.
A job from the first tenant's repositories that still targets the old label then lands on the second tenant's runners.

**Read from source, not measured** (Q1325's reviewer, 2026-11-11, at #2306 head `4b373bc`).
No AGC path calls `DeleteRunnerScaleSet`, and [Finding and pruning orphan scale sets](../development/testing.md#finding-and-pruning-orphan-scale-sets) records that a rename leaves the old one registered.
Admission releases the name as soon as the rename or delete is stored, so a second tenant in the same scope can claim it.
That tenant's listener runs `ensureScaleSet`, `GetRunnerScaleSetByName` returns the orphan as an exact match, and it is adopted.
If the second tenant declares no runner group, the orphan keeps the first tenant's group (the `!pinned` return); if it declares one, `UpdateRunnerScaleSet` moves the orphan into it.
Q1325 removed the stale session a rename used to leave on the old scale set, which made this worse while it lasted, but not the adoption.

**Same root, smaller cost.** After a rename, a reaped worker pod minted under the old name fails `scalesetlistener.MintedBy` against the new one, and the new listener's start-up sweep lists only the new prefix, so the old name's runner records are never deregistered.
That is a records leak rather than a boundary.

**Fix direction, not decided.** Delete the old scale set when a listener stops for a rename or its set is deleted, once its jobs have drained, so the name is released at GitHub as well as in the cluster; that would also take its runner records with it, which is unmeasured.
Otherwise state the adoption in `05-security.md` as an accepted residual with the operator step that closes it.
A measurement first: whether deleting a scale set at github.com removes its runner records and fails or requeues its queued jobs.
