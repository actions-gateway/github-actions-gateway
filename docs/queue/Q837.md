# A `run-parallel` exit 143 means the gate was killed, not that it failed

Measured 2026-08-12: `signal 15, exit 143` is an external kill, and `run-parallel.sh` waits on every pid rather than killing siblings. Count primary failures by `(exit N)` with N < 128, or a contention kill reads as a real gate failure.
