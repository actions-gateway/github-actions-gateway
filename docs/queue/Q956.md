# Re-vendor `queue.py` for the citation window the worker contract assumes

`session-worker`'s contract tells a worker that `queue.py lint` reports citation drift as an advisory note and that its `CITATION_WINDOW = 10` suppresses drift of ten lines or fewer outright, so the check can wait until after an edit.
Measured 2026-08-21: this repo's vendored copy has no `CITATION_WINDOW` and no drift-window logic at all, because it predates upstream `f969655`, which added it.
So a worker here follows an instruction about behaviour its own tool does not have.
Re-vendoring picks it up, and `make vendored-skills-check` then needs its digest re-stamped in the same change.
[Q955](Q955.md) owns the detection half, that nothing asks whether the vendored files have moved upstream; this row is one measured instance of the drift that row cannot see.
