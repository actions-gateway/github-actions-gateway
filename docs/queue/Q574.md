# One gate for every path list the workflows write twice

Three shapes, three bespoke checks: shared paths across two `filters:` (Q533), `on.push.paths` vs its filter (gated), `pull_request.paths` vs `push.paths` (ungated). One registry replaces all three, over Q584's `devtools/ci/pathfilters` parser.
