# EgressProxy logLevel godoc cites debug lines that do not exist

The godoc says "per-CONNECT debug lines dominate log volume under load", but `handleConnect` has one `Debug` call and it fires only when the CONNECT-200 write fails — no line is emitted per connection.
It becomes the generated CRD description, so an operator reads a volume warning for traffic the proxy never logs, and sizes a pipeline against it.
Found reviewing Q564, which added `auditLogging` directly beside it; that field's volume claim is true, which is what makes the neighbour misleading.
