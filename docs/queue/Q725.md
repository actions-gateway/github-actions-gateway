# Security and compliance dashboard for the audit persona

The proxy's opt-in per-connection audit record (Q564) attributes per pool by default, and per tenant and per job only where the operator has turned on both halves of the Q986 attribution pair (`ConnectionsWithSource` plus `WorkerAddresses`).
So a dashboard keyed on the consumer has to say which of the two it is reading, and show nothing rather than the pool's traffic when the pair is off.
The Security persona needs evidence produced unprompted: per-tenant egress attribution, admission rejections, abuse signals.
