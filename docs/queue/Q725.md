# Security and compliance dashboard for the audit persona

The proxy's opt-in per-connection audit record (Q564) attributes per pool, so it is per tenant on an unshared pool (the default) only.
Its seven fields carry no consumer identifier, so on a shared pool nothing keyed on the consumer can find that consumer's traffic: it is filed under the pool ([Q986](Q986.md)).
The Security persona needs evidence produced unprompted: per-tenant egress attribution, admission rejections, abuse signals.
