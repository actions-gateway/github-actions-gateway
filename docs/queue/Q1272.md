# Remove the classic code nothing can reach

Q264 removed classic acquisition from the AGC and the GMC, and left code only classic called.
None of it can run in a supported install, which is why it is not a `v2.0.0` gate: each item below says where it lives and why nothing reaches it.
It is dead weight that keeps a second protocol dialect compiling and tested.

**What is left, measured 2026-11-02 by `git grep` on the Q264 branch and re-checked 2026-11-03:**

- **The classic broker client**, [`broker/client.go`](../../broker/client.go) and its tests: `CreateSession`/`GetMessage`/`AcquireJob`/`RenewJob`/`CompleteJob`/`DeleteSession`.
  Unreachable: its importers are `cmd/probe` and `broker/brokertest` alone, neither of which is a published image (`publish.yml` builds `gmc`, `agc`, `proxy`, `worker`, `wrapper`, `build-runner` and `cache-runner`); the AGC imports only `scaleset`.
- **[`broker/brokertest`](../../broker/brokertest/) and [`broker/brokerstub`](../../broker/brokerstub/).** Test-only.
  The AGC envtest suite still starts `brokertest.New()` in `suite_integration_test.go`, but only for its `HTTPClient()`, which `v2_multigateway_test.go` and `v2_runnerset_scaleset_test.go` hand the provisioner for REST calls; replace that with a plain test client before deleting the package.
  Deleting `brokertest` retires [Q804](Q804.md) and [Q1049](Q1049.md), both defects in it.
- **fakegithub's classic control API** in [`test/fakegithub/main.go`](../../test/fakegithub/main.go): `/control/enqueue`, `/control/sessions`, `/control/session-versions`, `/control/acquirejob`, `/control/singleuse`, `/control/redelivery`, `/control/jobstats`, and the broker endpoints behind them.
  Test-only: fakegithub is not published, and no e2e spec calls these after Q1274; `/control/reruns`, `/control/runstate` and `/control/scaleset/*` serve the scale-set specs and stay.
- **`cmd/probe`'s classic modes**, including `abandoned.go` and `compat`'s broker checks.
  Unreachable from an install: probe is a developer tool run by hand, not a published image.
- **The worker's M3 pipes handoff** in [`cmd/worker/main.go`](../../cmd/worker/main.go): the payload-Secret → `Runner.Worker spawnclient` path classic used.
  It ships in the `worker` image and runs only when `WORKER_MODE` is unset, which no AGC-built pod is: `buildPod` guarantees a container named `runner` and `setScaleSetWorkerMode` sets `WORKER_MODE=scaleset` on it in the only provision path (`provisioner.go`).
  Removing it makes the scale-set mode the default rather than an env-selected branch.
- **The provisioner's classic admission and eviction paths.** `Provisioner.Admit` and the `runnercore.AdmitFunc` / `AdmitOutcome` types it returns have no non-test caller; the `AdmitReason*` constants stay, because the scale-set capacity advertiser labels its withhold metric with them.
  `handleEviction`'s classic branch, the in-process `evictionCounts` budget, runs only when `tier` is not `evictionTierScaleSet`, and all four non-test callers (`eviction_scaleset.go`, `oom_class.go`, `orphaned_scaleset.go`, and `abandoned_rerun.go` via `stranded_recheck.go`) pass `evictionTierScaleSet`; the same holds for `forceCancelAbandonedRun`'s classic branch.
  `evictionTierClassic` appears on 36 lines of `eviction_internal_test.go` and `abandoned_rerun_internal_test.go`.
- **Comment narration.** 209 comment and code lines across 51 AGC files still mention the classic tier (`git grep -c -i -w -E 'classic|AcquireJob' -- 'cmd/agc/*.go'`, excluding `vendor` and `test/load`).
  Q264 fixed the ones that stated something false; most of the rest compare the scale-set path against code that no longer exists ("identical to the classic path", "classic parity"), which the comment standard's no-history rule rules out.
  Some still state something false, read 2026-11-05: `api/apiconditions/conditions.go` around lines 556 and 578 says `RunnerVersionTooOld` has two producers and that the classic listener publishes `VersionAccepted`, and no non-test code publishes either session reason.
  `listener.go`, `metrics.go`, `runnerset_scaleset.go`, `provisioner.go` and `eviction_scaleset.go` hold the most.
- **The live-GitHub e2e suite's classic specs** in `cmd/gmc/test/e2e/github_e2e_test.go`.
  Test-only, and credential-gated: no workflow sets `GITHUB_E2E_*`, so CI never runs it.
  Six of its seven specs ran on classic through `RunnerTenant` and `AGC_EXTRA_GITHUB_ORG_URL`, which the AGC no longer reads; `E2E_GitHub_QuotaBlockedJobRunsOnSibling` measures classic redelivery and has no scale-set meaning.
  Porting it needs a live run to verify, which is why it did not ride with Q1274's e2e port.

**Done when** `git grep` finds no importer of `broker` outside `cmd/probe`'s remaining scale-set modes, fakegithub serves no classic route, the worker has no payload mode, and no AGC code path takes a classic tier.
