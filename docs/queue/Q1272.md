# Remove the classic broker client, fakegithub classic API and probe modes

Q264 removed classic acquisition from the AGC and the GMC, and left the code that only classic called but that lives outside those two binaries.
None of it ships in an AGC or GMC image, so it is not a `v2.0.0` gate; it is dead weight that keeps a second protocol dialect compiling and tested.

**What is left, measured 2026-11-02 by `git grep` on the Q264 branch:**

- **The classic broker client**, [`broker/client.go`](../../broker/client.go) and its tests: `CreateSession`/`GetMessage`/`AcquireJob`/`RenewJob`/`CompleteJob`/`DeleteSession`.
  Its importers are now `cmd/probe` and `broker/brokertest` alone; the AGC imports only `scaleset`.
- **[`broker/brokertest`](../../broker/brokertest/) and [`broker/brokerstub`](../../broker/brokerstub/).** The AGC envtest suite still starts `brokertest.New()` in `suite_integration_test.go`, but only for its `HTTPClient()`, which `v2_multigateway_test.go` and `v2_runnerset_scaleset_test.go` hand the provisioner for REST calls; replace that with a plain test client before deleting the package.
  Deleting `brokertest` retires [Q804](Q804.md) and [Q1049](Q1049.md), both defects in it.
- **fakegithub's classic control API** in [`test/fakegithub/main.go`](../../test/fakegithub/main.go): `/control/enqueue`, `/control/sessions`, `/control/session-versions`, `/control/acquirejob`, `/control/singleuse`, `/control/redelivery`, `/control/jobstats`, and the broker endpoints behind them.
  No e2e spec calls them after Q264; `/control/reruns`, `/control/runstate` and `/control/scaleset/*` serve the scale-set specs and stay.
- **`cmd/probe`'s classic modes**, including `abandoned.go` and `compat`'s broker checks.
- **The worker's M3 pipes handoff** in [`cmd/worker/main.go`](../../cmd/worker/main.go): the payload-Secret → `Runner.Worker spawnclient` path classic used.
  The scale-set mode execs `run.sh --jitconfig`.
- **The GMC's now-unread AGC env vars.** [`actionsgateway_v2_builder.go`](../../cmd/gmc/internal/controller/actionsgateway_v2_builder.go) still injects `GITHUB_ORG_URL` and `GITHUB_RUNNER_VERSION`, which no AGC code reads after Q264.
  Dropping them changes the AGC pod template, so every AGC rolls once on upgrade; `docs/operations/upgrade.md`'s env table lists `GITHUB_RUNNER_VERSION`, and `cmd/agc/names/runner_version_test.go`'s comments describe it as the `agent.version` GitHub validates.
- **The live-GitHub e2e suite's classic specs** in `cmd/gmc/test/e2e/github_e2e_test.go`.
  Six of its seven specs ran on classic through `RunnerTenant` and `AGC_EXTRA_GITHUB_ORG_URL`, which the AGC no longer reads; `E2E_GitHub_QuotaBlockedJobRunsOnSibling` measures classic redelivery and has no scale-set meaning.
  This one is credential-gated and needs a live run to verify, which is why it did not ride with Q264's e2e port.

**Done when** `git grep` finds no importer of `broker` outside `cmd/probe`'s remaining scale-set modes, fakegithub serves no classic route, and the GMC injects no env var the AGC does not read.
