# Parallel githubapp tests break each other through http.DefaultTransport

**Event:** any `TestToken_*` in `githubapp`, or `TestDeregisterRunner_Statuses` in `cmd/probe`, fails on `main` with `http: CloseIdleConnections called` in the error.

Sighted once, on the `push main` run of `35d1ccb4a` (#1999, run 36649692418, 2026-09-30), in `unit-test`'s `-race` step.
The merge-group run of the same tree had passed 20 minutes earlier.

```text
--- FAIL: TestToken_NonOKResponse (0.00s)
Error: "githubapp: POST access_tokens: Post \"https://api.github.com/app/installations/1/access_tokens\": net/http: HTTP/1.x transport connection broken: http: CloseIdleConnections called" does not contain "401"
```

**Mechanism, read from the Go 1.27.1 source.** Every `httptest.Server.Close` calls `CloseIdleConnections()` on `http.DefaultTransport` (`net/http/httptest/server.go` line 514).
For a response with no body, the transport's read loop parks the connection as idle *before* handing the response to the caller (`net/http/transport.go` lines 2532-2548).
If a sibling's `Close` lands in that gap, the caller sees the connection close, finds no response waiting yet (line 3086), and returns `errCloseIdleConns`.
So only header-only responses are exposed: `NonOKResponse`'s bare 401 was, and the bodied 201s in the same file were not.

**Reproduction.** The real tests did not go red under stress on the unchanged tree: 0 failures in 500 and in 1,500 iterations under `-race` (`-cpu 8 -parallel 32` for the second).
An in-package hammer calling `CloseIdleConnections` in a loop found nothing either, because the transport's `closeIdle` flag then stops connections being parked at all, and a noisier sibling exhausted local ports before it hit the window.
A standalone amplifier with `NonOKResponse`'s shape went red with the CI text: a header-only 401 POST through `DefaultTransport` from 8 goroutines while another goroutine calls `CloseIdleConnections`, under `-race`, failed 422 of 16,000 requests.
The same amplifier with a cloned transport passed 5 runs of 16,000 with no failure.

**Fix.** `testClientRedirectingTo` clones the transport per client, and `TestDeregisterRunner_Statuses`, whose handlers also answer header-only, uses `srv.Client()` instead of `http.DefaultClient`.

**Idiom sweep**, per [sweep the idiom](../development/maintaining-backlog.md#flake-fixes-go-first).
`git grep -n 'http\.DefaultTransport' -- '*.go' ':!vendor' ':!tools/vendor'` names one test helper routing requests through it, the one fixed.
Implicit uses (`http.Get`, `http.DefaultClient`, a bare `&http.Client{}`) in the 444 non-vendored `_test.go` files that call both `httptest.New` and `t.Parallel()` found six more sites.
One was exposed, `TestDeregisterRunner_Statuses`, and is fixed.
The other five sit outside the window because they get bodied responses or send no request: four in `cmd/probe/abandoned_test.go` (`TestDecodeJobRequest_EncryptedBody` starts no server) and `broker/egress_ip_test.go`'s `http.Error` 405.
