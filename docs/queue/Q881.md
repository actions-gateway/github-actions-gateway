# `plan-hygiene` skips a PR that only adds a plan doc

Its `plan` filter matches `docs/plan/README.md`, `docs/STATUS.md` and `**.go`, not `docs/plan/*.md`, so a PR adding only a plan doc skips the job that catches its missing row.
