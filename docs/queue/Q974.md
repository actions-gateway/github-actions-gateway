# `cmd/probe` sits below its coverage floor, passing only on tolerance

**Re-measured 2026-09-04 08:35 PDT** on a quiet tree at `origin/main` (`f792d60c5`), `make cover-check` exit 0: `./cmd/probe` reports 81.6% against a recorded floor of 81.8%, and passes only on its 0.5000pp tolerance, which the gate itself flags.
The module this row was filed against has moved.
`./cmd/proxy` now reads 80.8% against an 80.8% floor, exactly at it after a re-record, and `./cmd/agc` reads 83.1% against 83.0%, so both of the 2026-08-24 instances are gone and only the class survives.
Read the row for the class, not for a module name: it is whichever module the ratchet is currently absorbing, and it changes under you.

The same reading was taken independently three times on 2026-09-04 and agreed each time: by the [Q989](Q989.md) session on `origin/main` before its fix, by a merged-set lint over the whole open batch after it, and by this one on the merged trunk.
That matters because [Q989](Q989.md) changed how the tolerance denominator is computed, and `./cmd/probe` at 2,253 statements sits past the 600-statement crossover, so it takes the fixed 0.5pp under the old per-row denominator and the new per-block one alike.
The number is therefore not an artifact of that change.

The baseline drifts between re-records rather than moving with any one change, which is what makes the margin a standing condition rather than an incident.
Nothing watches the margin, so the failure mode is quiet: a floor the tolerance is absorbing asserts progressively less, and the first loud signal is a real regression arriving after the slack is spent.

**The fix wants a quiet tree, which is why this is a row rather than a hunk.** `make cover-update` rewrites `coverage-baseline.txt` for every module at once, so it collides with any branch whose diff moves a covered line; there were 17 open PRs when this was filed.
Re-record when the tree is quiet, and decide at the same time whether a floor that only tolerance keeps green should re-record downward at all, or whether `cmd/proxy` wants tests instead.
