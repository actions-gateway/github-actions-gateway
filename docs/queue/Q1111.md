# webhookretry's budget test measures the host, not the retry loop

`shrinkRetryPacing(t, 50*time.Millisecond, time.Millisecond)` gives the retry loop a 50ms wall-clock budget, and the test then asserts `calls > 1` ("it should have retried before giving up").
Nothing in that assertion is about the retry loop.
`retryOnTransientWebhookError` computes `deadline := time.Now().Add(webhookRetryBudget)` and stops as soon as `time.Until(deadline) <= 0`, so the assertion asks whether a second closure call plus one 1ms `time.After` fits inside 50ms of wall clock, which is a property of the host.
A first call descheduled past 50ms, which is one scheduling quantum on a saturated box, returns after one attempt and the assertion reads `1 > 1`.

**Found by the idiom sweep that closed Q1089**, which was the same shape in `cmd/agc` and did fire: red at load average 82.64 on 2026-09-09, green twice on the same tree.
This instance has **never been observed failing**, so it is filed rather than bumped to the top under the flakes-first rule.
Its margin is wider than Q1089's, since the op is an in-process closure rather than two loopback HTTP round trips plus a goroutine handoff, but the class is identical and the box runs at load 30-75 routinely.

**The work.** Make the attempt count a property the test fixes rather than one it races the host for.
Q1089's repair is the model: the loop's two timers become nil-defaulted seams, and the stub closes the budget on the attempt it wants to be the last, so exactly one select case is ever ready and the assertion becomes an exact count.
`webhookretry.go` reads its clock as `time.Now()` plus `time.After(webhookRetryGap)`, so both need a seam, which is why this was left out of Q1089's PR: it is a production change in a second module, and that PR was scoped to `cmd/agc`.
Widening the budget is not a fix, only a wider race.
The sibling case at `cmd/gmc/migrate/webhookretry_test.go:55` (`shrinkRetryPacing(t, 5*time.Second, time.Millisecond)`, asserting `calls == 3`) is already sound: the op decides when to stop refusing, and the budget only has to not expire.
