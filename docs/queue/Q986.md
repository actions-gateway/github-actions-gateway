# Egress audit record cannot attribute a tenant on a shared proxy pool

The record's `namespace` comes from the downward API, so it names the POOL.
`spec.sharing.allowedNamespaces` lets one pool serve consumers elsewhere and a CONNECT carries no namespace, so a shared pool's records cannot say which tenant reached a destination.
Q564 documented the limit rather than closing it: the only field that would close it is the client source IP, and adding it to every record is a per-worker movement log nothing has weighed.
Matters for [Q725](Q725.md), whose audit persona wants per-tenant egress.
Distinct from [Q567](Q567.md), which is bandwidth isolation on a shared pool, not attribution.
