# Egress audit record carries no identifier for who made the connection

Its seven fields name the pool, the destination, and the byte counts, and nothing about the caller.
Two gaps fall out of that one absence.
**Tenant:** `namespace` is the downward-API pool namespace, so on a pool shared via `spec.sharing.allowedNamespaces` a record cannot say which consumer reached a destination.
**Job:** no field ties a connection to a job on ANY pool, so [secure-multi-tenant-oss-ci.md](../plan/secure-multi-tenant-oss-ci.md) Definition of Done #5, "which host each job reached", is unmet even unshared.
Both need a per-connection source identifier first, which Q564 declined: the client IP on every record is a per-worker movement log nothing has weighed.
Neither closes on that alone: tenant needs IP to namespace, job needs IP to pod to the AGC's mapping.
Matters for [Q725](Q725.md).
Distinct from [Q567](Q567.md), bandwidth isolation rather than attribution.
