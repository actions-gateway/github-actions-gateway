# No updatecli manifest can be dry-run before it runs unattended

[dependency-updates.md](../development/dependency-updates.md#running-it-locally) documents `updatecli diff` as the local dry run, but `updatecli` is in neither `check-tools.sh`'s registry nor `CONTRIBUTING.md`'s prerequisites, so `make doctor` passes without it and nobody has it.
Both name it, only as the bumper of *other* tools' pins (checked against #1673, which reworked that registry), so a grep hit there is not this row being fixed.
Ten manifests now ship unexercised: a `matchpattern` that stops matching is silent, and the doc's own "manifest rot" note says the tell is a long-stale pin with no PR.
Register it as `optional`-tier, or gate the patterns another way.
Found writing `updatecli.d/cosign.yaml`, where the patterns were checked by re-implementing the substitution in `python3` instead.
