# Complete v1 removal (full v2-only)

The `actions-gateway.github.com` group (`v1alpha1`) leaves in two halves, and the GMC half is on `main`: no v1 `ActionsGateway` API, webhook, reconciler or chart surface, and no `gag-migrate` v1→v2 fan-out, the binary staying for `storage-version`.
What is left is the AGC half: the `RunnerGroup` API in `cmd/agc/api/v1alpha1` (36 files under `cmd/agc` import it, measured 2026-11-01), the AGC's v1 reconciler, the chart's `runnergroup-crd.yaml` and the GMC-bundled copy `scripts/manifest/sync-chart-crds.sh` keeps in step with it, the `runnergroups` arm of the `priorityclass-allowlist-guard` policy, the chart checks' `RunnerGroup` probes in `scripts/e2e/`, and `apinames.RunnerGroupAgentStem`, the AGC agent pool's last v1 name.

Between the two merges `main` serves the v1 `RunnerGroup` with no GMC that creates one, and the RunnerSet agent-identity guard no longer reads `RunnerGroup`s, so a hand-applied `RunnerGroup` named `rs-<x>` could claim a RunnerSet's stem unchecked.
No release can ship in that window: the next tag cut from `main` is `v2.0.0`, which waits on this row.

`v2alpha1` belongs to the `actions-gateway.com` group and is [Q1167](Q1167.md)'s, with `v2beta1`.
The chart CRDs carry `helm.sh/resource-policy: keep`, so an upgrade that drops one orphans it in-cluster rather than deleting stored objects; making the `v1`→`v2` migration mandatory in the operator docs is [Q1107](Q1107.md)'s, and binds the tag rather than either PR.
