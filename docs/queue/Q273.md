# Complete v1 removal (full v2-only)

Blocked on the 1.10 tag: `v2.0.0` is the only breaking release, so once a removal is on `main` the next tag cut from it is `v2.0.0`.
Front door, banners, and `gag-migrate` are done; what is left is removing the `actions-gateway.github.com` group (`v1alpha1`) and `gag-migrate`, whose only input it is.
`v2alpha1` belongs to the `actions-gateway.com` group and is [Q1167](Q1167.md)'s, with `v2beta1`.
Deleting a CRD deletes every object of its kind, so the operator docs Q1107 owns have to make the `v1`→`v2` migration mandatory before this ships, not after.
