# Only the host platform's cosign digest is asserted

`download-cosign-test.sh` derives the platform from `uname` and asserts a pinned digest for that one, so a `COSIGN_VERSION` bump that adds only the linux lines passes CI and breaks `make cosign` on every Mac, which is where `make verify-release` is actually run.
The table in [download-cosign.sh](../../scripts/release/download-cosign.sh) carries four platforms; assert all four, not the one the test happens to run on.
Found while adding Q903's pin gate, which compares version strings and never reads the table.
