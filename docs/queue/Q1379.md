# A tenant can pre-claim scale-set names in a GitHub org it cannot reach

**A tenant can bind a gateway to a GitHub org it holds no credentials for and claim scale-set names there, and another tenant who does hold that org is then refused at admission for those names.** Confirmed from source by the November security audit (2026-11-09), low severity; one of the five findings Q1323 carried, filed on its own because its fix is a design choice the other four did not need.
It is a denial of service on names, not a path to anyone's jobs: the claiming tenant still cannot open a session without credentials for the scope.

Admission's cross-tenant name guard counts every stored (`githubURL`, `runnerLabels[0]`) pair as a first-come claim (`cmd/gmc/internal/scalesetscope/scalesetscope.go:187:func Of(`), and nothing on that path binds the claiming gateway to authority over the scope it names: no credential read, no gateway condition, no namespace-to-org binding.

The audit gives two directions, and choosing between them is the design question:

- **Count only authenticated claims across namespaces.** A cross-namespace claim blocks another tenant only once its gateway's AGC has authenticated to the scope, read from a status condition set after a successful installation-token exchange.
  Status is GMC- and AGC-written, so the tenant cannot set it, but it leaves a window before the first exchange.
- **A platform-owned allowlist of GitHub scopes per tenant namespace**, enforced in the `ActionsGateway` webhook, so a tenant cannot bind a gateway to an org the platform has not assigned it.
  It closes the gap outright and adds a platform object to maintain.

Same-namespace and same-gateway collisions stay unconditional under either.
Whichever is chosen, `docs/design/05-security.md` states the first-come behaviour that remains between tenants who both hold the org.

This is not Q1344, which is about a scale set left registered at GitHub after its name is released; this one is about a name claimed in the cluster by a tenant with no reach at GitHub.

**Done when** a cross-namespace claim from a gateway with no authority over its scope no longer refuses another tenant's `RunnerSet` or gateway, pinned by a webhook or envtest case that is red under today's guard.
