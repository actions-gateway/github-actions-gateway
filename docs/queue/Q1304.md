# Drop the code paths below the 1.35 floor

The charts now refuse a cluster below Kubernetes 1.35, so version checks written for older clusters no longer choose anything on a supported install.
Read from the code on 2026-11-06, not run.

The AGC's `useImageVolume` (`cmd/agc/main.go:754`) compares the server version against 1.33 and uses an initContainer below it, and that comparison now always picks the image volume.
The initContainer path itself stays reachable, through `WRAPPER_DELIVERY=init` and when the server version cannot be read, so whether it goes too is open.
`release.md`, `migration-from-arc.md`, `tenant-onboarding.md` and `features.md` describe the 1.33 split and move with the answer.

The `t.Skipf` guards on a server below 1.31 in `v2_crd_test.go` and `v2_multigateway_test.go` can never skip while `ENVTEST_K8S_VERSION` is 1.35.

Done when no branch tests for a version below the floor, and the docs describe what remains.
