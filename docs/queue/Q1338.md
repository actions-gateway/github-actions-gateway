# Resolve the API base for GHE.com data-residency hosts

**A gateway whose `githubURL` names a GitHub Enterprise Cloud data-residency tenant, such as `https://octocorp.ghe.com/acme`, is addressed as a GitHub Enterprise Server (GHES) appliance.** `githubapp.DeriveAPIBaseURL` maps only `github.com`, `www.github.com` and `api.github.com` to `https://api.github.com`, and every other host to `https://<host>/api/v3`.
Read from source at `b5edaef1b`: that example derives `https://octocorp.ghe.com/api/v3`.
`git grep ghe.com` at the same commit matches nothing, so no other code models these hosts either.
[Q1333](Q1333.md) is a different defect in the same function: it covers the three public GitHub hosts written with odd case or a trailing dot, and fixing it leaves a `*.ghe.com` host on the GHES branch.

The correct API base is unverified.
GitHub's documentation, recalled rather than read for this row, puts the REST API for a GHE.com tenant at `https://api.<tenant>.ghe.com`.
Confirm it against GitHub's current docs before coding to it, together with the Actions registration path the scale-set client posts to (`<apiBase>/actions/runner-registration`).
What a GHE.com gateway does today is also unmeasured: registration probably fails, but nobody has tried, and trying needs a GHE.com tenant with a GitHub App installed.

The egress side needs the same check.
The EgressProxy referrer filter matches a built-in list of GitHub hosts, and whether a GHE.com tenant's API and Actions hosts reach the proxy allowlist was not read for this row.

The fix is a resolver branch, not user-declared host aliases.
Q1322 finding 6 showed that the scale-set scope guard has to agree with this resolver about which spellings name one place, and an alias list written by tenants would let one tenant decide another's scope.

**Done when** `DeriveAPIBaseURL` derives the documented API base for a `*.ghe.com` host, a table case covers it, the egress host list is checked for the same tenant, and `docs/operations/` says GHE.com is supported or names what is missing.
