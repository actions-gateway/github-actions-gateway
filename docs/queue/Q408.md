# Untrusted-PR egress posture for Kata workers

Phase 1 validated 2026-08-24: four green self-hosted Kata runs name no non-GitHub non-registry host, graded against a Phase 0 control that fires on both.
Phase 2 is done as of 2026-08-28: the mirror manifests, over five upstreams rather than four once the grading added `gcr.io`, are validated on the dogfood cluster at 25 of 25 checks by `scripts/dogfood/e2e-mirror-validate.sh`.
Every instance serves a real upstream manifest, refuses uploads with 405, and exposes no debug listener, so the mirrors are measured serving rather than merely applied.
Phase 3 is done as of 2026-08-28: dockerd via a mounted `daemon.json`, the non-Hub docker refs rewritten at the one chokepoint every `docker pull` shares, buildkit given a generated `buildkitd.toml`, and helm's OCI ref pointed at the ghcr mirror.
Validated on the dogfood cluster by a green Kata run (75 of 75 specs) whose five instances served 161 content requests, against a zero baseline measured on the same cluster twenty minutes earlier, so the reading is a change rather than a number.
The repositories attribute each client separately: the OCI chart can only be helm's, `distroless/static` only buildkit's, cert-manager and metrics-server only the rewritten refs, `kindest/node` only dockerd's own mirror.
Phase 4 is built as of 2026-08-28 and its validation is the outstanding work: the Kata overlay ships no additive egress policy any more, so a worker there reaches cluster DNS, GitHub and the five mirrors and nothing else.
What says so is `scripts/e2e/egress-negatives.sh`, run from inside the job on every run of the lane rather than once, because a policy that stops selecting the worker is invisible in a green suite.
Three destinations must not answer (a mirrored upstream by its own hostname, the plain internet, the metadata server on port 80), each paired with a control that must, since a battery of unreachable checks passes identically on a worker with no network at all.
It books a dogfood session: nothing on a cluster has graded any of it, so until that session runs the posture is a design rather than a measurement.
Then Phase 5 flips the docs and closes the row.
