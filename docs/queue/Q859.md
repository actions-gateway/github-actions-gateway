# piped-gate's overlap probe judges the hook's checkout, not the session's

`pipedgate` takes its repo root from the registry path, probing the hook's own worktree.
`EnterWorktree` breaks that: the session keeps the launch checkout's hook, so PR-create and push flagged overlaps this branch lacks.
A cwd fix reverses it.
