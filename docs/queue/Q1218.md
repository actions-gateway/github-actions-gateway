# Reconcile the first cosign v3 release candidate's chart on Flux

[`publish.yml`](../../.github/workflows/publish.yml) signs with cosign v3.1.4 and passes `--new-bundle-format=false --use-signing-config=false` on every `sign`, `attest` and `sign-blob`, so v3 writes the format operators already verify ([release.md](../operations/release.md), the "signer writes the v2 signature format" bullet).
What has not been measured is the keyless path and Flux.

Measured 2026-10-27 against a local `registry:2` with a throwaway key pair and no transparency log:

- v3.1.4's **default** `sign --recursive` and `attest --type spdxjson` are invisible to cosign v2.5.2, which reports `no signatures found` on the index, the child, and the attestation, with or without `--new-bundle-format`.
  Cosign v3 stored them under the OCI referrers fallback tag (`sha256-<digest>`) instead of `sha256-<digest>.sig`.
- With the two flags, v2.5.2 verifies all three, and the `.sig` and `.att` manifests match v2.5.2's own output in media type and annotation keys.
- `sign-blob --bundle` with the flags writes the old bundle JSON, which v2.5.2 and v3.1.4 both verify.
  The v0.3 bundle that v3 writes by default also verified under v2.5.2.
- Cosign v3.1.4 verifies the published, keyless, v2-signed v1.10.0 with `scripts/release/verify-release.sh` (all eight artifacts OK).

Unmeasured: keyless signing adds a Fulcio certificate and a Rekor entry, which the key-pair runs never wrote, and no Flux version was run against a v3-signed artifact.
`make verify-release-compat` now runs every cosign v2 check on each candidate: `verify-release.sh` with the cosign v2.5.2 that `COSIGN_COMPAT_VERSION` pins, covering image signatures, the per-arch SBOM attestations, both charts and the Release's blob bundles.
It passed all 22 checks against the v2-signed v1.10.0 on 2026-10-27, and the release-candidate skill and release.md both call it.
What it cannot reach is Flux.

Done means: on the first release candidate signed by v3, before it is promoted, `make verify-release-compat` passes and the chart reconciles through an `OCIRepository` with `verify.provider: cosign` on a current Flux.
