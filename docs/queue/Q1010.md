# A dispatcher's error reaches further than its correction

A framing written into a spawn brief propagates to every artifact the worker touches, while the correction that follows reaches the one sentence its author is looking at.
The two travel at different rates and nothing in the playbook says so, which leaves a corrected claim looking closed while its copies stand.

Measured 2026-08-27 on [#1753](https://github.com/actions-gateway/github-actions-gateway/pull/1753).
A dispatcher brief asserted that Phase 2's validation batched onto Phase 3's dogfood session.
That was wrong, and it reached three files: the plan doc's status header, the plan index's row, and a `deploy/` README the worker wrote *from* the brief.
The worker corrected the framing where it had been raised and reported the class closed, in good faith.
Re-reading the remote head found all three original sites still wrong, and the eventual census came to six once two artifacts no tree walk reaches were counted: the backlog row, and the commit message.

The worker's own sweep then missed the same `deploy/` README a second time, because a plus-or-minus-2-line context window narrowed the population before the count, so a clean result confirmed nothing.
That failure is [Q918](Q918.md)'s class and is filed there.
What belongs here is the propagation asymmetry that made the sweep necessary at all.

Two rules the playbook can state.
A dispatcher that finds an error in its own brief owns the census, not the worker, because the dispatcher is the only party that knows every place the brief was sent.
And a census over a repository is a floor rather than a total: a commit message and a backlog row are artifacts a brief reaches and `grep` over the worktree does not.

The same shape recurred twice more in the run on [#1754](https://github.com/actions-gateway/github-actions-gateway/pull/1754), where a PR body's overstated sweep claim ("three sites") had also reached the backlog row and an architecture doc, and where a fabricated attribution in that body was found by a stood-down takeover rather than by the author or the reviewer.
A PR body is the artifact class no gate in this repository reads.
