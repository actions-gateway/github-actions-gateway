# Onboard new tenants on actions-gateway.com/v2, not v2beta1

Every onboarding surface still tells a new tenant to write `actions-gateway.com/v2beta1`, and `v2.0.0` removes it.
From 1.10 every kind stores `v2` ([Q1086](../plan/release-1.10.md)), so a tenant onboarding on `v2beta1` today writes manifests they must rewrite before 2.0.
The maintainer made it a 1.10 blocker on 2026-10-26, after the 1.10 website reconciliation found it and no row scheduled it before [Q1107](Q1107.md)'s 2.0 docs cut.

**Measured 2026-10-26** with `git grep -c 'actions-gateway\.com/v2beta1'` on `origin/main` at `02638465b`: the heaviest pages are `docs/operations/tenant-onboarding.md` (8), `docs/getting-started.md` (7), `docs/index.md` (5) and `docs/operations/migration-from-arc.md` (5), with `README.md`, the three `deploy/templates/*/template.yaml` and the generated field reference behind them.
The prose recommends it too: `README.md:248:**New tenants should onboard on` and the `getting-started.md` tip "New tenants: start on `v2beta1`".

**The old reason for `v2beta1` no longer holds.** `getting-started.md` told tenants to stay on `v2beta1` if they might roll back to a release that does not serve `v2`; from 1.10 the only rollback target is `v1.9.0`, which serves `v2` (`docs/operations/upgrade.md:187:**Rolling back** to `v1.9.0` is safe`).

**`v2` is not a pure rename.** Its `EgressProxy` omits the `CiliumFQDN`/`CalicoFQDN` `egressPolicyMode` aliases (`api/v2/groupversion_info.go:14:// egressPolicyMode enum is CIDR;FQDN, without the deprecated CiliumFQDN/CalicoFQDN`), so every moved example has to validate at `v2`.

**Out of scope:** pages that are *about* `v2beta1` (deprecation, upgrade and migration history, the storage sweep) keep naming it, and the chart's `PriorityClassAllowlist` stays on `v2beta1` because changing a chart voids the running `v1.10.0-rc.1` validation.

**Done when** every page and shipped template that tells a new tenant which version to write says `actions-gateway.com/v2`, and says `v2beta1` stays served until `v2.0.0`.
