# A doc-gate run is void the moment you edit again, and nothing says so

Measured 2026-08-12: 4 `make check` runs in one session, 3 voided by one-line prose edits made while the gate ran. The rule says run the doc gates once the prose is written; nothing says stop editing first, so both halves read as compliant.
