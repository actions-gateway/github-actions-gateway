# A plan enumerates readers, not references, and grep cannot see a reader

Q889's stated scope was understated in all five phases that measured it, always the same way: it counted textual references, and what bit was what *reads* the thing.
Phase 6 alone missed three, each found by a gate or a build rather than by reading.
The three shapes grep is blind to: a frontmatter field, a build-time hook whose missing-file path returns success, and a pathspec glob that crosses directory separators.
Write the rule where plan docs are specified.
