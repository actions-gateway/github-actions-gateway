# Measure what running GAG costs a single team against ARC

The site stopped telling a single team to use ARC on 2026-11-07 and now says the team gets every GAG capability and that the running cost against ARC is unmeasured (`docs/alternatives.md` § Which option fits, `README.md` § Is this for you?, appendix D.3's verdict).
That sentence is the claim this row retires: nothing has measured it, in either direction.

What a measurement is: the same runner set, same worker image, same job mix, once under ARC `gha-runner-scale-set` at its current release and once under GAG at the release being compared, on the dogfood cluster, reading at rest and under load the control-plane pod count, requests and measured usage (AGC, GMC, proxy pool if any, against the ARC controller and its listener pods), and the install steps a single team takes from an empty namespace to a green job.
Install steps are a count of commands run and objects applied, not minutes, since minutes measure the operator.

Done when `alternatives.md`, `README.md` and D.3 carry the figures with the ARC version and date they were read at, or carry the reason the comparison cannot be made.
Whichever way the numbers fall is written; the row exists to replace "unmeasured", not to win.
