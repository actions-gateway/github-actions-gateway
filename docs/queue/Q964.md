# head_snapshot crashes on a tracked file absent from the working tree

`head_snapshot` lists files with `git ls-files` (the index) and then opens each, so any unstaged deletion of a tracked `.md`/`.go`/`.yaml` raises `FileNotFoundError` and reddens `make claude-usage-test`.
That is the normal state of a session mid-deletion, which is exactly when `make check` runs.
The [sibling loop](../../claude-usage/compute_metrics.py) about 200 lines below already skips on `OSError`.
