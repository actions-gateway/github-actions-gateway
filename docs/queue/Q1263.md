Retyping first would mean reading both values back from conversion annotations, code Q264 then deletes ([the boundary](../plan/q1167-v2-retype-split.md#where-q264s-boundary-falls-before-the-agc-retype)).
The second of three PRs that let [Q1167](Q1167.md) delete `api/v2alpha1` and `api/v2beta1`.

Once classic is gone the swap is mechanical, measured 2026-11-02: 20 AGC non-test files and 72 tests import `v2alpha1` or `v2beta1` off `7b292627a`, with Q273's deletions subtracted.
`v2_detect.go` then asks the REST mapper about `RunnerSet` at `v2`, which every release since 1.9 serves.
`integration/conversion_webhook_test.go` and `v2alpha1_crd_test.go` stay as they are; Q1167 deletes them.
If time is short this folds into Q1167 as one PR once [Q1262](Q1262.md) has landed.
