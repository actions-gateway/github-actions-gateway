# Validate seven release and CI pipeline leads from the security audit

**Leads, not confirmed vulnerabilities.** Source supports each path and something outside the repository decides the outcome, so none has a severity.
[Each lead, with evidence, blockers and a validation plan](../plan/security-audit-2026-11.md#release-and-ci-leads):

- publish.yml dispatch `tag` input is never compared with the dispatch ref, so one tag's source can be published and signed under another version name while the stop-ship gates evaluate the named version (needs validation).
- Release verification identity pattern accepts a publish.yml signature from any v* tag for any version (needs validation).
- Historical publish.yml copies at 28 v* tags have no validated-candidate gate and accept a free-form version name, under a signing identity verify-release accepts for any version (needs validation).
- pages.yml publish job deploys dispatch-chosen content from any ref and serves the whole gh-pages branch (needs validation).
- Dependabot sync and rebase writers compile and run a freshly bumped build tool in a job holding a contents:write token (needs validation).
- No source-visible control stops a fork pull request from naming a dogfood scale-set label in runs-on (needs validation).
- go-throttle hook returns `allow` for single `go build`/`go test` commands whose flags or GOFLAGS run a caller-named program or write to a caller-named path (needs validation).

**Read the repository settings before the `v2.0.0` tag.** Four of the seven turn on who may create a `v*` tag, who may dispatch `publish.yml` and `pages.yml`, and whether a deployment environment protects either.
If those are restricted to maintainers, the four are same-principal and close with that reading recorded.
The fork-pull-request `runs-on` lead belongs with [Q1220](Q1220.md), which decides what the gateway refuses to run for a fork.

**Ask:** the first four settle from the repository's tag rulesets, workflow-dispatch permissions and environment protection, which only a maintainer can read.
**Measure:** the other three have a local test in the plan doc.

**Done when** each lead is either confirmed and fixed, refuted with the measurement recorded, or written into `05-security.md` as an accepted residual with its bound.
The plan doc gives each one a bounded local test and the fact an owner has to observe.
