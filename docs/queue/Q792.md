# Report the runner version a worker pod actually ran back to the AGC

Q715 judges the image *reference*, so a digest-only or custom tag reports `Unknown`; the wrapper reads the real version from `Runner.Listener.deps.json` and only logs it.
Needs a channel out of the worker (termination message) and a status field.
