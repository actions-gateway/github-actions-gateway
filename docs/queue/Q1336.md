# GMC brackets an IPv6 API-server NO_PROXY entry, which net/http ignores

**On a cluster whose API server ClusterIP is IPv6, the GMC writes that address into the AGC's `NO_PROXY` in brackets, and Go's `net/http` exempts nothing for a bracketed address with no port.** `apiServerNoProxyEntry` brackets an IPv6 `KUBERNETES_SERVICE_HOST` on the stated ground that the parser reads a bare `fd00::1` as host `fd00:` port `1`.
The measurement is the reverse.

Measured on go1.27.3 on 2026-11-10, with `http.ProxyFromEnvironment` in a fresh process per value, `HTTPS_PROXY` set, and the URL `https://[fd00::1]:443/api`:

| `NO_PROXY` | Result |
|---|---|
| `[fd00::1]` | proxied |
| `kubernetes.default.svc,svc.cluster.local,localhost,127.0.0.1,[fd00::1]`, the string `buildNoProxy` produces | proxied |
| `fd00::1` | direct |
| `[fd00::1]:443` | direct |

The same URL without a port answers the same way in each row, and an IPv4 control (`10.96.0.1` against `https://10.96.0.1:443/api`) is direct.
`TestMatchesAgreesWithNetHTTP` in `cmd/gmc/internal/webhook/noproxy` pins the bracketed, bare and bracketed-with-port forms against the same address.

**What that costs an operator is not measured.** The expected effect is the one Q465 recorded for IPv4: the AGC's Kubernetes API traffic goes to the tenant's egress proxy and the AGC crash-loops at startup.
No IPv6 cluster was run, so that is inferred.
The AGC's API client was read and not run: client-go wraps the same function in `NewProxierWithNoProxyCIDR`, which delegates to it unless `NO_PROXY` holds a CIDR that contains the address.
So a tenant `noProxyCIDRs` entry covering the Service range would hide the defect.

The fallback path already emits the working form.
When the GMC's own `KUBERNETES_SERVICE_HOST` is unset it writes the literal `$(KUBERNETES_SERVICE_HOST)`, which the kubelet expands to the bare address.

`TestBuildNoProxy_BracketsIPv6APIServer` asserts the bracketed form and its comment repeats the claim, so the test passes on the defect.

**Done when** `apiServerNoProxyEntry` emits a form `net/http` honours for an IPv6 ClusterIP, a test asks `net/http` about the string `buildNoProxy` produces for an IPv6 and an IPv4 address and fails on the bracketed form, and the comment on the function states the measured behaviour with the Go version it was measured on.
