# Validate release candidates in CI instead of a local dogfood gate

Auditable, keyed to the tag, and replaces the `refs/validated/` marker a maintainer's local gate writes today.
Milestone 1 (keyless CI identity) is code plus a one-time bootstrap a maintainer runs; milestone 3's workflow cannot go green until that bootstrap and the identity probe have.
Milestones 2 to 4 remain: the gate's tools on a Linux runner, the tag-triggered workflow, and `publish.yml` reading its verdict.
