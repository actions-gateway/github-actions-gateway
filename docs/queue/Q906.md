# Report workers that bind and never start on an ungated RunnerSet

Q714 made this visible only through `spec.capacityGate`, which is an intake decision and off by default, so an ungated set still says nothing for `pendingPodDeadline` while its pods sit in `ImagePullBackOff`.
`WorkersUnschedulable` is correctly silent (the scheduler said yes).
Publish the observation as its own advisory condition, gate or no gate, mirroring how `WorkersUnschedulable` reports without deciding.
