# DeriveAPIBaseURL reads a mixed-case or dotted GitHub host as GHES

**A gateway whose `githubURL` is `https://GitHub.com/acme` is admitted and then addressed as a GitHub Enterprise Server (GHES) appliance.** `githubapp.DeriveAPIBaseURL` compares `u.Hostname()` with `github.com`, `www.github.com` and `api.github.com` by exact string, and Go's `url.Parse` keeps the host's case.
Measured 2026-11-10 on go1.27.3 with a copy of the function body at `a29ab647d`: `https://github.com/acme` derives `https://api.github.com`, and `https://GitHub.com/acme` derives `https://GitHub.com/api/v3`.
Nothing upstream normalizes the host.
`validation.GitHubURL` checks the scheme, that a host is present, and the path, and the CRD pattern checks only the `https://` prefix.

What the gateway then does is unmeasured.
The GMC injects the derived base as `GITHUB_API_BASE_URL`, so the AGC's token exchange and its scale-set calls go to `GitHub.com/api/v3`.
Whether github.com serves that path, redirects it, or returns 404 was not tried, and trying it needs a GitHub App installation.

A trailing dot does the same.
Measured the same way: `https://github.com./acme` derives `https://github.com./api/v3`, although `github.com.` resolves as `github.com` does.

The other two readers of the same host already ignore case.
`scalesetscope.GitHubScope` lowercases the host and drops a trailing dot before building its scope key, and the EgressProxy referrer filter does the same before matching the built-in GitHub host list.
So the scale-set name guard and the egress policy treat this gateway as public GitHub while the AGC addresses it as an appliance.

**Done when** `DeriveAPIBaseURL` matches the three public hosts without regard to case or a trailing dot, a table case covers each, and the stored `githubURL` is left as written.
