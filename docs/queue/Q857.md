# A `COSIGN_VERSION` bump never re-downloads, so the old verifier stays

Q842 gave each Go tool rule its pin file; cosign's pin is a make variable, so `$(COSIGN)` has no file to depend on and make skips an existing binary. The fail-closed digest table in `download-cosign.sh` only runs if the rule does.
