# go-work-tidy.sh needs GNU realpath, which no tool check lists

`go-work-tidy.sh` line 103 runs `realpath --relative-to="." "$mod_dir"` for every module `go list -m all` returns. macOS ships a BSD `realpath` at `/bin/realpath` that rejects the flag (`realpath: illegal option -- -`), and `scripts/ci/check-tools.sh` does not list `realpath` at all, so `make doctor` cannot warn.
Measured 2026-09-07 on two Macs reviewing #1858, isolated runs on both: `make tidy-check` passes and its log carries no realpath line, because line 95's producer, `go list -f '{{if not .Main}}{{.Dir}}{{end}}' -m all`, exits 1 on a vendored workspace with `go: can't compute 'all' using the vendor directory` (also under `GOWORK=off` and `-mod=mod`), its stderr goes to `/dev/null` behind `|| true`, and the empty result means the loop never reaches line 103.
So on macOS the dependency-ordering step is silently dead rather than passing, and the GNU-only flag would fail the script the first time that step ran.
One reviewer run did fail at line 103 with `realpath: illegal option -- -`; it ran concurrently with `make vendor-check`, whose `go work vendor` re-vendors the tree mid-run, and it did not recur in isolation, so it is recorded here as an unreproduced sighting rather than a host difference.
The same review also saw one isolated `make tidy-check` on the PR head report `go.work.sum` drift (58 `/go.mod h1:` lines wanted) with the repeat on the same head clean and CI green; unreproduced, recorded so a later sighting reads as a second one.
CI runs the script on `ubuntu-latest`, where `go list` succeeds and `realpath` is GNU, so the gate is sound there and its ordering step is exercised only there.

Two fixes, either sufficient: replace the call with a `--relative-to`-free form ([bash-style.md](../development/bash-style.md) prefers portable builtins), or add `realpath` to `check-tools.sh` with a GNU-flag probe the way it probes other tools' modes.
Doing the first makes the second unnecessary.
Found in review of #1858 (Q929); the PR did not touch `scripts/`.
