# A tracing endpoint that parses but cannot deliver needs a signal

Admission now rejects an endpoint the exporter would misread, which was the part gated on `v2.0.0`.
These parse, so that check admits them, and an operator finds out only by reading the AGC's log or the policy.
[Reaching the collector](../operations/observability-logging.md#reaching-the-collector) documents the first.

- **A proxied tenant's short name.** `otel-collector.observability:4317` and `otel-collector.observability.svc:4317` are sent through the egress proxy, whose own NetworkPolicy blocks them, so no spans arrive whatever `spec.tracing.networkPolicy` says.
  Measured 2026-11-03 against 5c46c1b on kind with Calico.
  A CEL rule on the `ActionsGateway` cannot see the pool's `NO_PROXY`, so this is a status condition or a webhook warning, and neither breaks a stored object.
- **An out-of-range port.** `https://c:70000` parses, and the export fails with `name resolver error: produced zero addresses` (`otlptracegrpc` v1.47.0, measured in-process).
  `tracingEgressPort` falls back to 443 for it, so the reconcile is unharmed.
- **A `dns:///` target.** `tracingEgressPort` finds no port in `dns:///collector:4317` and opens 443 unless `networkPolicy.port` says otherwise.
  The exporter delivers to it in-process, so on an enforcing CNI the rule opens the wrong port.
- **A stale collector rule.** While the IP cache serves no ranges, `preserveExistingEgress` keeps a policy's rules, and `servedGitHubRules` excludes only the spec's current collector rule, so an old CIDR rule on 443 can read as the GitHub rule in that status message.
  Read, not run.

Routing the export through an `EgressProxy` with `destinationFQDNs`, rather than exempting the collector with `NO_PROXY`, is a third answer to the short name that nobody has measured, including what it costs in worker egress.

Done when a proxied gateway naming a collector the proxy would carry gets a signal an operator sees without reading the AGC's log, and a measurement of the `EgressProxy` route either adopts it or records why not in [Reaching the collector](../operations/observability-logging.md#reaching-the-collector).
