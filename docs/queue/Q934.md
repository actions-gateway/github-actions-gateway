# Worker contention sweep false-positives on unrelated histories

`git diff --quiet origin/main...$b` exits non-zero on a branch with no merge base, so the contention sweep reads `origin/gh-pages` as touching the file.
Measured 2026-08-18 and again 2026-08-21, where it was the only reproducible false positive in the loop.
The upstream half shipped in `karlkfi/claude-skills` commit `bae3cbe` on 2026-08-21, which skips a branch whose merge base cannot be read and loops over `b` rather than the `path` that destroyed `PATH` under zsh.
What is left is this repo's own copy: [parallel-dispatch.md](../development/parallel-dispatch.md) still prints the unguarded loop and still carries the caveat naming this row, so adopt the guard in the snippet and drop the caveat with it.
