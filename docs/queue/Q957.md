# Withdraw a dispatch chip once its session has run

A spawned chip stays pending until someone starts or dismisses it, so a closed batch leaves one live invitation per worker to redo work that has already merged.
Measured 2026-08-21: seven chips from the batch that landed that morning were started a second time, hours after all twelve of its PRs had merged, and their briefs carried contention stamps seven hours stale.
Nothing in the playbook says to withdraw a spent chip, and `spawn_task`'s `task_id` is the handle dismissal needs, so the tracker's chip column should record it.
Upstream is the same gap one level up: `spawn_task`, `dismiss_task` and `task_id` appear nowhere in either session skill, filed 2026-08-21 as gap 10 of `karlkfi/claude-skills` issue 288.
The dispatcher-side rule this repo can state without upstream is narrower and worth having on its own: **a message to a session that has not reported to you is a question, never an instruction**, because ownership is established by a worker's first report and nothing covers the window before it.
Two workers outside the batch received a stand-down aimed at that window and were saved by checking a stranger's instruction rather than obeying it.

A sharper case than a spent chip, measured 2026-08-27: a chip whose *premise* is refuted while it is still running.
`dismiss_task` withdraws only a chip nobody has started, so once a takeover was underway its brief could not be recalled even though the dispatcher had established forty minutes earlier that the author it named was alive.
It kept working, rebased, and produced a complete local fix before surfacing, and nothing stopped it except that session choosing to ask before it pushed.
So the tracker recording a `task_id` is necessary and not sufficient: the dispatcher also needs a way to reach a *started* chip, which today is a message to whichever session holds it and there is no way to learn which one that is.
The mitigation available now is the one that worked: a takeover pins `--force-with-lease` to the head it observed, so a collision with the real author fails instead of clobbering.
