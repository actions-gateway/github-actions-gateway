# Port the e2e suite from classic to the scale-set tier

[Q264](Q264.md) removes classic acquisition, and the fake-GitHub e2e suite runs on it: its fixture pins `acquisitionProtocol: Classic` and its specs enqueue through fakegithub's classic broker sessions.
The e2e lanes run only in the merge queue (Q675), so Q264 cannot clear the queue until the suite runs on the scale-set tier, and this lands first, on a `main` that still has both tiers.

**What the port needs, measured 2026-11-02 on `main` at `abb6fcd`:**

- **A fakegithub `githubURL`.** The AGC points a scale-set listener at the stub only when the gateway's `githubURL` host already is fakegithub's (`cmd/agc/internal/controller/runnerset_scaleset.go:573`), and every fixture tenant carried `https://github.com/e2e-org`.
- **A per-set first label.** fakegithub runs one `scalesetstub.Stub`, which keys scale sets by id and looks them up by name alone (`ScaleSetIDByName`, `handleGetScaleSetByName`), so names are global across specs and orgs; the fixture names each set's scale set after the RunnerSet.
- **Admin JWTs that survive the next mint.** The stub held one admin token and replaced it on every runner registration, so with every tenant on one stub each registration revoked the others' connections; the client re-mints only near expiry, so a revoked tenant 401s on `generatejitconfig` for the token's hour (measured 2026-11-03 in `E2E_AGC_WorkerPodLifecycle`).
  The stub now keeps every minted token valid, so clients sharing it stop revoking each other.
- **The specs that only classic can express go:** `acquire_admission_test.go` (the pre-acquisition gate's per-delivery refusal), `singleuse_selfheal_test.go` (agent recycling), and `job_lifecycle_test.go`'s session and delivery specs.

**Not in this row:** the live-GitHub suite, `github_e2e_test.go`.
It also builds tenants with `RunnerTenant`, so the port changes it, and it needs App credentials to verify; no workflow sets `GITHUB_E2E_*`, so CI skips it.
Its port goes in the residue row Q264 files (Q1272), not here.
