# Docs name the retired `lint-backlog.sh` as the live backlog linter

Q889 retired it with the table; `queue.py lint` (`make queue-lint`) and `check-queue-rules.py` (`make queue-rules-check`) carry its rules now.

Measured 2026-08-30 by reading each file rather than a merged grep, after Q924 cleared [maintaining-backlog.md](../development/maintaining-backlog.md): six docs still describe it as live, so this row's original count of four was low.

- [queue-id-allocation.md](../development/queue-id-allocation.md) has four, attributing rules 10 and 12 to it.
  Both attributions are wrong beyond the name: `check-queue-rules.py`'s own docstring records rule 10 as deliberately absent, dropped on measurement at the cutover, and rule 12 as `queue.py claims`.
- [parallel-dispatch.md](../development/parallel-dispatch.md) has three, two of them naming it as a `make check` sub-gate to read by name in the output.

- [backpressure.md](../development/backpressure.md) and [technical-debt.md](../development/technical-debt.md) have one each.

Three code comments repeat it and are not covered above: `scripts/ci/gate-list-test.sh`, `scripts/lib/merge-keyed-records.awk` and `.github/workflows/status-lint.yml`.

Nothing executable is broken, so this is a naming defect rather than a rename.

The test that yields six is whether a sentence would send a reader to run the script today; a sentence recording what the script did is history and stays.
