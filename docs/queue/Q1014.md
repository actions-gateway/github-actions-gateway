# errexit-prologue gate exempts an executable suite under lib/

`scripts/ci/check-errexit-prologue.sh` requires `set -euo pipefail` plus `shopt -s inherit_errexit` in every executable script under `scripts/`, and exempts `*/lib/*` on the reasoning that a sourced file runs under its caller's shell options.
That marker is positional, and a `*-test.sh` is the case it gets wrong: the repo convention puts a suite beside its subject, so a library's own suite lives in `lib/` and `SCRIPTS_TESTS` runs it by path, with its own shell and its own need for the prologue.

Measured 2026-08-28: `scripts/lib/registry-mirror-test.sh` is the first such file, and it is exempt from this gate while being an entry point.
No defect today, because it carries the prologue; what is missing is the gate's ability to notice if it stops.

`check-script-modes.sh` had the identical gap and was corrected in the same PR by reading the `-test.sh` suffix ahead of the `lib/` marker, with both directions and a no-widening case asserted in `check-script-modes-test.sh`.
The fix here is that same one-line reordering in `is_exempt`, plus the matching assertions.

Not urgent: one file, and the prologue it would check is present.
