# Docs teach bare two-dot `git diff origin/main` for a branch's own scope

Two-dot against a moving ref shows main's commits as yours: measured 2026-08-12, a post-rebase read listed 9 files the branch never touched.
The merge-base rule is scoped to backlog lint; CONTRIBUTING teaches the bare form with no caveat.
