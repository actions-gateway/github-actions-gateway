# Remove deprecated classic acquisition machinery

It follows the `v1alpha1` removal (Q273), since classic was `v1alpha1`'s only acquisition path.
It no longer waits for the `v2alpha1` drop: removing classic while `v2alpha1` still serves a `Classic` set would run that set as ScaleSet, and would skip scale-set label uniqueness, but only a `v2.0.0` candidate cut early could ship that state, and the cut waits on every removal.
It lands before [Q1263](Q1263.md), the AGC retype onto `v2`, which cannot compile while the AGC reads `acquisitionProtocol` and `maxListeners`; the completing change deletes those reads, and the field declarations leave with the `v2alpha1` package in [Q1167](Q1167.md) ([the split](../plan/q1167-v2-retype-split.md#where-q264s-boundary-falls-before-the-agc-retype)).
`v2beta1` is ScaleSet-only, so classic serves only v1alpha1/v2alpha1 objects and comes out in the same `v2.0.0` bundle, not separately.
Strips every read of `acquisitionProtocol`/`maxListeners`, including the conversion-annotation reads the GMC makes in `cmd/gmc/internal/webhook/v2/runnerset_webhook.go` (`acquisitionProtocolOf`, the label-uniqueness skip) and `cmd/gmc/internal/scalesetscope/scalesetscope.go`.
Removing classic also retires [Q416](Q416.md), a classic-listener defect parked until classic removal slips, so the completing change deletes that row too.
