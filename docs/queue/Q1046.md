# Port the roadmap merge driver to Go and delete `merge-keyed-records.awk`

Phase 2 of [merge-drivers-go.md](../plan/merge-drivers-go.md).
Phase 1 moved the shared runtime, the keyed-record set merge and the two table drivers to `devtools/git/`; the roadmap driver is the last caller of the `awk`, so the file goes with it.

The work this driver holds beyond a table merge is the bullet encode/decode: a list is a maximal run of top-level `- ` bullets, every one of which must carry a `<!-- q:QN -->` annotation, and a bullet's continuation lines and trailing blanks are folded onto one record line with `\001` so the set merge sees one record per line.
The blank-line counts ride *beside* the records rather than inside them, and `decode_records` applies the same three-way rule to the spacing that the records themselves get, with the last surviving record taking the list's trailing count rather than its own.
Without that override, deleting a tight list's final bullet welds its predecessor to the next heading.

Port that faithfully; it is the part with no Go equivalent yet.
`MarkerKey` (the `<!-- q:QN[,QM…] -->` reader, normalized to a comma-joined ID list) is not written yet either, because Phase 1 only needed `LinkKey`.

Validation is the same shape Phase 1 used and must not be weakened: `scripts/docs/git-merge-roadmap-test.sh` passes with no change to its assertions, and an `awk`-versus-Go differential over generated three-way cases agrees on stdout *and* exit status before the `awk` is deleted.
Phase 1's harness is the model, and it needs the case corpus to reach every refusal class, which the first corpus did not (two classes never fired until the generator was extended).

Phase 1 left the `awk`'s `link` mode with no caller, which is Q1043's defect class again.
Deliberately not churned, since this row deletes the whole file and Q1043's mandatory-`key_mode` guard already refuses an unknown mode outright, so nothing can reach a dead reader by accident.
If this row slips, that is the thing to revisit.

Deleting `scripts/lib/merge-keyed-records.awk` also retires `scripts/lib/merge-keyed-records-test.sh` and its `mk/gate-lists.mk` entry.
