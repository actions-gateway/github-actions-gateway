# Five low-severity confirmed findings from the November security audit

**Five boundary slips confirmed from source on 2026-11-09, each narrow and none needing a major to fix.** Nothing was run, so each result is what the code determines, not what a cluster showed.
[Each finding, with evidence and the smallest fix](../plan/security-audit-2026-11.md#confirmed-low-findings):

- Share and attribution projection names collide for (ns 'a-b', proxy 'c') and (ns 'a', proxy 'b-c') (confirmed, low).
- ActionsGateway defaultProxyRef status tells a tenant whether a named EgressProxy exists in another namespace (confirmed, low).
- An attributed namespace named 'ca' overwrites the attribution CA in the clients Secret and forces a bundle regeneration on every reconcile (confirmed, low).
- A direct-egress gateway's workload NetworkPolicy permits direct GitHub egress for proxied workers in the same namespace, while their status reports Proxied and attributed (confirmed, low).
- A tenant can pre-claim scale-set names in a GitHub org it holds no credentials for, and another tenant's RunnerSet or gateway is then rejected at admission (confirmed, low).

The direct-egress one also contradicts two operator-facing statements, `docs/design/05-security.md:147` and `docs/operations/troubleshooting.md:3936`, so its fix includes the docs whichever way the policy goes.

**Done when** each has its fix and a test that fails without it, or a recorded decision to accept it as a documented residual in `05-security.md`.
