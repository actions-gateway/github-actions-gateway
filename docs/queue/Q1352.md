# Reconcile the no-worker-toleration rule with the Dragonfly node client

**Two operator pages give contradictory placement advice for the Dragonfly node client.** [security-operations.md § Keep GAG's control plane off worker nodes](../operations/security-operations.md#keep-gags-control-plane-off-worker-nodes) says not to give the worker pool's toleration to "any cache or mirror", and its threat table lists cache and registry mirrors as pods whose node a worker escape poisons.
[p2p-image-distribution.md](../operations/p2p-image-distribution.md#gags-dragonfly-node-client-recipe) tells operators to set the node selector and toleration in `deploy/dragonfly-node/client.yaml` to "your worker nodes", and the gated "Untrusted pull requests at scale" profile applies that recipe on every Dragonfly leg.
Read on 2026-11-16: `client.yaml` is a DaemonSet with `hostNetwork: true`, a privileged init container, and `hostPath` mounts of `/var/run/dragonfly` and `/etc/containerd`, and it tolerates dogfood's `dedicated=e2e` taint.

The client has to run on the nodes it serves, because it is the proxy containerd on that node pulls through, so the security page's rule cannot hold for it as written.
The fix is to name node-layer clients as an exception on the security page and state what a worker escape on such a node reaches.
That residual is not measured.
A node-level escape can read the client's local blob cache and its containerd config; whether it can serve a poisoned blob to *another* node's pull depends on whether that pull checks the blob digest end to end, which nobody has tested here.

Separate from Q1206, which drops a reference-architectures caveat once a release candidate's gate runs the node client; this row is about the security page's placement rule, which Q1206 does not touch.

**Done when** the security page's placement guidance names node-layer P2P clients as the exception and says what an escape on their node reaches, and p2p-image-distribution.md links that statement, with the cross-node poisoning question either measured or stated as open.
