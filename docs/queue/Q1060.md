# Round-trip the conversion webhook on real objects (GA soak criterion 3)

[v2-ga.md](../plan/v2-ga.md) Phase 1 criterion 3 requires the conversion webhook to have round-tripped every served version under real objects, including ones created before the `v2beta1` graduation, and no such reading exists.

The envtest fixtures cover the hop mechanically; what the criterion asks for is objects that lived on the dogfood cluster across the graduation, read back through each served version and compared field for field.
`deploy/dogfood-migrate` still carries a `v1alpha1` `ActionsGateway`, which is the pre-graduation object the criterion names, so the reading is available without manufacturing one.

The deliverable is the comparison recorded against the criterion in the plan's Phase 1 table, and the script that took it, so a later candidate can repeat it.
Rides in [release-1.8.md](../plan/release-1.8.md) rather than gating it, for the reason [Q1059](Q1059.md) gives.
Sibling: Q1059 owns criterion 2; [Q413](Q413.md) stays parked on both.
