# why-gag's stamp note names ARC 0.14.2 while its cells say 0.15.0

The note "What the current stamps were read against" in [why-gag.md](../why-gag.md#how-to-read-the-arc-column) says every ARC cell was read against `gha-runner-scale-set` 0.14.2, at commit `9bb16ae`, on 2026-08-12 and 2026-08-15.
The cells it describes are stamped `0.15.0 · 2026-10-04`, so a reader checking a cell is sent to the wrong commit.
Appendix D now cites those cells as its dated ARC reading.

Done when the note names the version, commit and dates the current stamps rest on, taken from whatever re-read them rather than assumed from the stamp.
