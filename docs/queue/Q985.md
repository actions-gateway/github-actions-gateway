# A bare Off enum value decodes as a YAML boolean

YAML reads bare `Off`/`On`/`Yes`/`No` as booleans, so an operator writing `auditLogging: Off` in a manifest sends the string `false` and admission rejects a value they never typed.
Measured with the repo's own vendored decoder: `sigs.k8s.io/yaml` turns bare `Off` into `false` and then into the STRING `"false"` for a string field, with no error of its own — the rejection comes later from the enum, naming `"false"`.
Affects `capacityGate.mode` and `agcAutoscaling.updateMode` too, so it is a convention question for api-review, not one field's bug.
