# Fixture builders as arguments hide a killed builder in six test suites

Six suites build fixtures inside a command substitution passed straight to an assertion helper, the shape [Q1145](Q1145.md) removed from `check-release-ladder-test.sh`.
Counted 2026-10-09 on `02fb0338b`, every `"$(builder` in argument position, on the helper's own line or a continuation, and not as an assignment:

- `scripts/docs/check-roadmap-test.sh`: 99 sites, `roadmap`, `status`, `features`
- `scripts/docs/check-release-pins-test.sh`: 15 sites, `fixture`
- `scripts/docs/check-release-links-test.sh`: 11 sites, `make_notes`
- `scripts/ci/check-publish-digest-test.sh`: 10 sites, `write_workflow`
- `scripts/ci/check-tool-pins-test.sh`: 8 sites, `write_makefile`
- `scripts/ci/check-cosign-pin-test.sh`: 2 sites, `write_makefile`

That is 145 in all.

Bash drops a substitution's exit status when it is an argument, so a builder that fails or is killed hands the helper an empty path, and the suite reports the checker's answer to that empty path as a wrong verdict.
Measured 2026-10-09 on `02fb0338b` against the release-ladder suite: a SIGTERM injected into its page builder produced a FAIL blaming the checker, with no shell error line; the same injection after hoisting the builder into an assignment exited 143, which `run-parallel.sh` reports as KILLED.
None of these six has been sighted failing this way, so this is a reporting defect rather than a flake.
Separate from [Q991](Q991.md), which is suites sharing a fixed fixture path so that one run deletes another's: that fix changes where fixtures live, this one how a builder's failure is reported, and neither closes the other.

**The census is scoped to fixture builders.** It matched the six helpers above by name.
Counting any local function substituted into a continuation-line argument reaches 17 suites, but most of those helpers return a value (a field, a rendered line) rather than a fixture path, so whether an empty result there can pass as a verdict is unassessed.
An earlier census of this row, matching only continuation lines that open with a builder-style name, found 4 suites and 35 sites; it missed every builder on the helper's own line.

**The fix** is the one Q1145 applied: assign each fixture (`page="$(fixture …)"`) and pass the variable, so errexit ends the suite with the builder's own status.
Re-run the census above after the change: every count should be 0.
