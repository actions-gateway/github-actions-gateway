# Escaped pipes in table code spans show a backslash on the site

A table cell holding a pipe inside a code span is written `a\|b`, which GitHub renders as `a|b`.
The MkDocs build keeps the backslash, so a reader of the published page copies a wrong value: the probe table's Investigation F selector shows `PROBE_RETENTION_TEST=arm\|check\|cleanup`.

Measured 2026-11-26 on a `make docs-build` of `site-dev/`, by searching the built HTML for `\|` inside `<code>`, queue pages excluded: 23 matches on 12 pages, three of them on `development/testing/`.
The count is of matches in the HTML; whether every one sits in a table cell is unchecked.
`operations/observability-dashboards/`, `operations/observability-metrics/` and `reference/api/` are among the pages, and `reference/api.md` may be generated.
