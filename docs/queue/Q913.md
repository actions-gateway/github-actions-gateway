# A gate's failure path is the one path no green run exercises

Q871's checker waited on the child's exit status in two places, so a fake dying during startup deadlocked it.
Every passing run avoided that path, and writing a fixture for it found the bug in one command.
A gate that hangs is worse than one answering wrongly, because `run-parallel.sh` just stops with no verdict.
Its siblings are already written down: a negative assertion must be able to fail, and causation is verified by deleting the mechanism.
This one is not.
Distinct from timing a gate, which the fan-out now reports: this is about exercising the error path.
