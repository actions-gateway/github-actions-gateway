# piped-gate lets a backgrounded gate report a trailing command's exit status

`make check > log; echo "EXIT=$?"; grep …` backgrounded reports `grep`'s 0, so a red gate reads green. It already denies a backgrounded call ending in `echo`/`\|\|`/`&`; this shape ends in a filter. Needs both-direction assertions.
