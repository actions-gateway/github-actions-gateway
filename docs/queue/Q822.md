# Three unrelated suites fail under concurrent load and pass on rerun

**Event:** a `scripts-test` suite fails inside a capped local fan-out and passes standalone straight afterwards, on `main`.

The mitigation is the cap: `run-parallel.sh` takes `RUN_PARALLEL_JOBS`, and the Makefile exports `local-throttle.sh jobs` as its default, physical cores minus 2 on a GUI dev shell and unbounded on CI or headless.
So `make check`'s 51-gate level and `make scripts-test`'s 119-suite level each start at most that many at once instead of all of them.
[The measurement](../development/testing.md#the-fast-gates-fan-out-past-the-heavy-build-semaphore): eleven runs on 2026-09-07 beside a sibling `go test -race` suite, load 26 to 153 on 18 cores.
Wall time cannot rank the caps, but every capped run spent 2,248 suite-seconds or fewer against 2,609 or more uncapped, and the fork+exec tail peaked at 1.8 s capped against 3.2 s uncapped.
That tail is the axis [Q1031](Q1031.md) re-keyed this row onto, and it moved with the width rather than with the load.

**What the mitigation is not evidence for.** No run crossed the 5 s budget Q1031's probe kills expire on, so that class is not reproduced here; it takes a second fan-out beside this one, which these runs had only from the `-race` suite next door.
8 against 16 is not separable in the data, so the default follows the throttle's own number, and [Q966](Q966.md) owns whether that number is right.

**Two sightings taken during the sweep belong to [Q912](Q912.md)**: `check-endpoint-parity-test` red with a `fakegithub` that never accepted within 30 s, once uncapped at load 77 and once at a cap of 16 at load 129, both green standalone.
They are recorded here rather than on that row because the run that produced them is this row's, and a groom moves them.

The original sightings: the `provisioner` eviction window under 8 workers on 2026-08-12, and `git-merge-script-index-test` at load 32.21 on 2026-09-04, the reading that showed load average was the wrong axis.
The `controller` 2m timeout in the original set is [Q823](Q823.md)'s, covered by the raise to 5m.
