# Measure whether a scale-set labels `PATCH` is honoured, and reconcile in place if it is

Q726 registers labels at create only, so appending one to a live set needs a fresh scale set. Whether the service honours a labels PATCH is unmeasured: ARC never patches, and Q712's group PATCH is stub-tested only. Probe before reconciling.
