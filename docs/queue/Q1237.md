# Record colocated egress proxy readiness in a failed job's snapshot

Q555's worker snapshot leaves out the readiness of the set's colocated EgressProxy, which the design lists beside the pod's own state (R7): a failed job whose proxy pool was not ready reads, today, as a red test on a healthy worker.
Add the EgressProxy's `Ready` condition and `readyReplicas` to the snapshot taken in `flaky_jobs.go`, read from the AGC's existing cache, with `proxy: shared` where the pool lives in another namespace the cache cannot see; an unready colocated proxy then counts as a platform fault and raises `PlatformFaultOnFailedJob`.
Deferred from Q555 to keep that change to the pod's own state, which needs no new read.
