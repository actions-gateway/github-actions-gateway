# Surface advertised capacity and withheld reasons in `RunnerSet` status

`adv.Withheld` reaches Prometheus only, so a tenant without metrics access cannot see why intake is throttled. Add `advertisedCapacity` and a per-reason withheld list to `RunnerSetStatus`. Q695's alerts cover the operator side; this is the tenant's.
