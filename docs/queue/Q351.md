# X25519 ECDH session-key exchange

**Decision:** we swap RSA-OAEP session-key delivery for X25519 ECDH (Appendix G.6) — makes Ed25519 the *secure* default and unblocks [Q11](Q11.md).
Until then RSA-3072/RSA-OAEP stays the secure default.
