# Reconcile the dashboard doc's panel tables with the shipped JSON

The page documents each dashboard row by row, and both sections have drifted from the JSON they describe.
Nothing compares them: `make promql-check` parses every panel expression out of the JSON (Q910) and never reads the prose, so a table that has lost a row, or gained a duplicate heading, is invisible to every gate.

Measured 2026-08-24 on `main`, two instances:

- The tenant section numbers its nine rows 1, 2, 3, 4, 5, 6, 7, **7**, 8.
  `grafana-dashboard-tenant.json` has nine correctly ordered rows, so **Reliability Signals** is Row 8 and **Fan-out Safety** is Row 9.
- The platform section's **Pod creation p99 by namespace** row has come out of the Cross-tenant Throughput table and is glued to the end of the Build Versions paragraph, where it renders as literal pipe-separated text mid-prose (line 175).
  The panel is real and sits in the Cross-tenant Throughput row of `grafana-dashboard-platform.json`; only the table entry moved.

One fix closes both: reconcile each section against its JSON.
Worth considering as part of it whether the reconciliation should be a gate rather than a one-off, since the drift is silent and the panel titles are already machine-readable on both sides.
