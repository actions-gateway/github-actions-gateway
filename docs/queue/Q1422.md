# Retire v1alpha1 narration from api/ comments that never reach a CRD

The Go comments under `api/` that controller-gen never copies into a CRD still describe `v2` by comparison with the `v1alpha1` API that `v2.0.0` removed.
Q1302 rewrote the godoc that becomes `kubectl explain` text and the API reference; Q1260 covers comments under `cmd/gmc` and `cmd/agc` only, so these sites sit in neither row.
The repo's comment standard is present tense with no history, and several name functions and types that no longer exist (`agcv1alpha1.ImpairingConditionTypes`, `securityProfileRank`, `effectiveProfile`), so a reader cannot follow them.

`git grep -n -i -E "v1alpha1|v1's|v1/v2|no weaker than v1|RunnerGroup CR" -- 'api/**/*.go' ':!**/zz_generated*'` finds them, once Q1302's change is on `main`:

- `api/v2/shared_types.go`: the label-domain block comment ("rather than the v1alpha1 actions-gateway.github.com domain", the v1/v2 dual-read window, the M5 migration tool), the `"managed"`/`"allowed"` value comments ("replaces v1's"), the SecurityProfile enum comment ("mirror … the v1alpha1 ActionsGateway.spec.securityProfile enum exactly, so v2 is no weaker than v1"), and the rank and effective-profile helpers ("v1's webhook-local securityProfileRank", "Matches v1's effectiveProfile semantics").
- `api/apiconditions/conditions.go`: the RunnerSetsDegraded rollup ("mirroring v1's RunnerGroupsDegraded", "the v1 agcv1alpha1.ImpairingConditionTypes aggregation"), the EgressProxy conditions ("porting v1's ActionsGateway …"), and the impairing set ("the v2 counterpart of v1's agcv1alpha1.ImpairingConditionTypes").
- `api/apinames/names_test.go`: `TestSegmentMatchesLegacyImplementations` lists "RunnerGroup CRs" among the live objects a regression would rename.
  Whether the test still guards anything once no `RunnerGroup` exists wants reading, not only the comment.

The dual-read sentence in `shared_types.go` reads as current behaviour and may now be false: on `main` at 2026-11-26, the only non-test Go files under `cmd/` and `api/` that name `actions-gateway.github.com` are that file and `cmd/gmc/migrate/main.go`.
That measures where the string appears, not whether anything reads the old domain, so check the VAPs and the downgrade webhook before rewording it.

This is a separate row from Q1260 rather than an extension of it so the two can be picked up independently; the change is comments only, so no generated file moves (`make codegen-check` confirms it).
