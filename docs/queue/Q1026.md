# Narrow the shared mirror's ingress peer from namespace to worker pods

The mirror-side ingress admits a *namespace*, not a workload: `registry-mirror-worker-access` names a `namespaceSelector` with no `podSelector` beside it, so every pod in an admitted namespace reaches port 5000 whether or not it carries `actions-gateway/component: workload`.

The base has the same shape and this is not a regression, but the [shared topology](../../deploy/registry-mirror/components/shared-tenants/kustomization.yaml) widens what it costs: the base admits any pod in **one** tenant namespace, the component admits any pod in **every** managed tenant namespace.
So a non-worker pod a tenant runs for its own reasons can reach a cache shared with tenants it is meant to be separated from, and can time its blob fetches there to learn what those tenants pulled.
Q1022 has since closed `/v2/_catalog` on every instance, so the repository list is no longer readable from that position; what this row narrows is the reachability itself.

The worker-side policy is already tight in the way this is not: `e2e-mirror-egress` selects `actions-gateway/component: workload` and nothing else.
ANDing that same selector into the ingress peer as a second key of one `from` element (not a second element, which ORs, per the comment in `base/networkpolicy.yaml`) would make the two halves agree.

**Do not ship it on that reasoning alone.** Whether every client that must reach the mirror carries the workload label is a cluster measurement nobody has taken, and the failure is fail-closed and total: a client that loses the path cannot pull at all, and the four wired clients read four different configurations ([README § How the job is wired](../../deploy/registry-mirror/README.md#how-the-job-is-wired-to-these-instances)).
Take it inside a Kata e2e window, where [`e2e-mirror-hits.sh`](../../scripts/dogfood/e2e-mirror-hits.sh) already reads each mirror's access log and is the instrument that would show a client silently dropping off.

Raised in review of the Q1020 PR, which shipped the shared topology and deliberately did not change this.
