# File upstream: karpenter kwok chart panics on its own defaults

At v1.14.0 the chart renders `featureGates.staticCapacity`/`.capacityBuffer` into `FEATURE_GATES` but values.yaml omits both keys; the empty string panics the controller at startup.
Q479's harness sets them explicitly as a workaround.
