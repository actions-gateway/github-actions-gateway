# v2 GA graduation (`v2beta1` → `v2`)

**Event:** the [Phase 1 soak](../plan/v2-ga.md#phase-1--the-soak-what-well-validated-means) closes. v1.3.0 shipped 2026-08-03 and two minors followed, so criterion 1 elapsed.
Criteria 2 and 3 were measured in the `v1.8.0-rc.1` dogfood window on 2026-09-14 and both came back positive: all five `v2beta1` kinds reconciled on the dogfood cluster, and the standing tenant's `ActionsGateway` round-tripped both served versions with identical specs ([the readings](../plan/v2-ga.md#soak-readings)).
That leaves criterion 4, the [v2-api.md](../plan/v2-api.md#definition-of-done-v2-ga) Definition of Done audit, which [v2-ga.md](../plan/v2-ga.md) records as still carrying two ❌ items: the `v2beta1` → `v2` graduation itself, which is this row, and the operator docs, which are Phase 4.
So the soak is no longer waiting on a measurement, and what remains is the work rather than the evidence.

**This spans two releases now, which is why it carries `1.9-gate` rather than `2.0-gate`.** Phase 2 — adding `v2` to the five kinds and serving it beside `v2beta1` — is 1.9's entire content and blocks that tag.
The storage marker and Phase 4's cut stay at `v2.0.0`: Rule #4b will not let storage advance in the same release that introduces `v2` ([why](../plan/release-ladder.md#why-19-exists-the-storage-version-cannot-advance-in-the-same-release-that-introduces-v2)).
Splitting the row is deliberately deferred until the soak closes and Phase 2 is actually startable, since the split is only useful once someone is picking the work up.
