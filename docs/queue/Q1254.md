# Read the run before expiring a parked re-run adopted past 24 h

Q1244 parks an out-of-memory re-run in the failure ledger's `pending` map until GitHub concludes the run, and expires an entry at 24 hours as `actions_gateway_eviction_rerun_failures_total{reason="run_never_concluded"}` plus an `EvictionRerunFailed` Event.
The age check runs before the run read, so an entry that is already past 24 hours when a restarted process adopts it is expired without any read of the run.
A run that concluded while no AGC was sweeping is then reported as never concluding, and the re-run its slot was reserved for never happens, though GitHub still accepts `rerun-failed-jobs` on a run that old.
This is the independent reviewer's reading of the Q1244 change, confirmed against the code and not measured in production: how often a parked entry outlives a whole process outage is unknown, and the window needs an AGC down for most of a day while a run is parked.
A fix takes one last run read before expiring and releases a concluded run as the sweep would have, keeping the 24-hour expiry and the attempt check for a run still in progress or already re-run.
