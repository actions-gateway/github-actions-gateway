# Move the main dogfood tenant off the doomed v2alpha1 apply version

`scripts/dogfood/setup.sh` applies its three main-tenant CRs at `actions-gateway.com/v2alpha1` (`ActionsGateway`, `RunnerTemplate`, `RunnerSet`), a version [Q452](../plan/v2-ga.md#decided-v2-omits-ciliumfqdncalicofqdn) removes at `v2.0.0` along with `v2beta1`.
Until then the release-validation gate exercises a version operators are being told to migrate off, and the apiserver says so on every run: the `v1.8.0-rc.1` validation drew three admission warnings, one per kind, reading `actions-gateway.com/v2alpha1 <Kind> is deprecated; use actions-gateway.com/v2beta1. v2alpha1 is served until v2.0.0, which removes it.` That is the [Q1085](Q1085.md) notice firing against this repo's own gate.

**The version is residue that later became load-bearing, which is why this is not a one-line bump.** The heredoc was authored 2026-06-28/29 (#435, #457); Q74 created `v2beta1` on 2026-07-06 (#557) and did not revisit it.
Both versions are `served: true` with `v2beta1` as storage (measured 2026-09-12 in `charts/actions-gateway-crds-v2/templates/crds/`), so applying at `v2alpha1` is a choice rather than a requirement, and it is the only thing in the dogfood path that crosses the conversion webhook, since the e2e tenant, `deploy/templates`, and setup.sh's own read-backs all resolve to the storage version.
It is therefore also the only live check that [Q279](../plan/v2-ga.md)'s `caBundle` wiring works: flipping the heredoc to `v2beta1` on its own deletes that coverage rather than improving it.

**Blocked on [Q1060](Q1060.md)**, whose deliverable is a deliberate, repeatable conversion round-trip on real dogfood objects.
Once that exists, the incidental exercise is free to go and this row is the flip plus its comment updates.
`deploy/dogfood-migrate`'s `v1alpha1` `ActionsGateway` is the better home Q1060 already names.

Sibling, not duplicate: [Q1059](Q1059.md) owns whether each kind has *carried traffic* and records the `v2alpha1` `RunnerTemplate` as acceptable coverage; its text needs the same edit when this lands.

`v2beta1` is the destination today and not the end of it: Phase 3 removes `v2beta1` at `v2.0.0` too, so whatever lands here moves again to `v2` with [Q273](Q273.md).
Prefer a form that does not name a version where one will do (setup.sh's existing `runnertemplate.actions-gateway.com` read-back is the shape); two operator-facing `kubectl patch runnersets.v2alpha1.…` instructions were already unpinned that way when this row was filed.
