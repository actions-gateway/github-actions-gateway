# promql-check and dashboard-render-check guard less than they read as

`promql-check` compares Alert/Record/Expr/Annotations only, so a `for:` or label drift passes at exit 0: the doc can promise a page while the rule ships a ticket.
`dashboard-render-check` reads committed refs, so it fires on an uncommitted re-render.
