Zero-idle self-hosted GitHub Actions runners for multi-tenant Kubernetes.

## Highlights

**[A tenant can no longer get round the raced scale-set name guard by creating its gateway with the GMC finalizer already set.](https://actions-gateway.com/2.0.1/design/05-security/#cross-tenant-job-acquisition-via-a-shared-scale-set-name)** The Gateway Manager Controller (GMC) passed a new `ActionsGateway` through admission once, by adding its finalizer, and the webhook refused that update while the gateway's scale-set name collided with another tenant's.
A gateway created with the finalizer already in place skipped it and was provisioned onto the held name.
The GMC now passes every gateway it has not yet written status for through one admission-checked update before provisioning it, which also covers a gateway restored by Velero, since Velero keeps finalizers (#2352).

**[A worker the Actions Gateway Controller (AGC) started for a job that another worker then ran is reclaimed, rather than idling on a node until its 12-hour lifetime runs out.](https://github.com/actions-gateway/github-actions-gateway/pull/2357)** GitHub could withdraw a job from a worker that was slow to start, re-issue it, and hand the re-issue back to that same worker.
The worker the AGC had created for the re-issue was then surplus, and the reclaim skipped it while it was still `Pending`, so it registered and waited with no job.
The AGC now reclaims a `Pending` worker when no idle `Running` one is left, and logs each job message it receives at Info (#2357).

**[On an IPv6 cluster, the AGC reaches the Kubernetes API directly, not through the tenant's egress proxy.](https://github.com/actions-gateway/github-actions-gateway/pull/2348)** The GMC wrote the API server's IPv6 address into the AGC's `NO_PROXY` in brackets, `[fd00::1]`, and Go's `net/http` ignores a bracketed entry with no port.

**[A gateway whose `githubURL` spells public GitHub in mixed case or with a trailing dot uses the public GitHub API.](https://actions-gateway.com/2.0.1/operations/security-operations/)** `https://GitHub.com/acme` or `https://github.com./acme` was treated as a GitHub Enterprise Server appliance, so the AGC's token exchange and scale-set calls went to `https://GitHub.com/api/v3` (#2347).

**[`build-runner` and `cache-runner` ship a newer Docker CLI, buildx and compose, which clears CVE-2026-78669.](https://github.com/actions-gateway/github-actions-gateway/pull/2344)** Two fixable HIGH findings remain in those binaries until a Docker release carries their fix, listed under **Security** below.

The end-to-end suite ran three times, on Kata Containers, on privileged Docker-in-Docker, and on Kata with the Dragonfly mirror back end, and each run's report holds 92 cases: 74 passed, 18 skipped and 0 failed.
The signed-CRD, storage and soak legs passed too, the storage leg found all six CRDs already at `storedVersions: ["v2"]`, and the run tore down to a cluster with no nodes.

`v2.0.1-rc.1` passed the same legs, and its teardown found the idle worker that #2357 fixes, so `rc.2` was cut to carry that fix.

## Security

**No security advisory accompanies this release**, and no externally reported vulnerability in this project's own code is patched.

**One dependency vulnerability is patched.** `build-runner`'s new `docker:29-cli` base clears CVE-2026-78669 from buildx's `golang.org/x/net`, and removes CVE-2026-78661 from buildx, though compose still carries it (#2344).
Two fixable HIGH findings in those binaries have no Docker release carrying their fix, so CI excuses each until 2026-12-17:

- CVE-2026-17106: `moby/go-archive` 0.2.0 in buildx v0.39.0, the newest buildx release, which waits on one linking go-archive 0.3.0.
- CVE-2026-78661: `golang.org/x/net` 0.60.0 in compose v5.7.1; compose v5.8.0 shipped 2026-11-17 and is not in `docker:29-cli` yet.

The other dependency bumps close no known vulnerability: Trivy finds nothing in the published `v2.0.0` `gmc`, `agc` or `proxy` images, and GitHub's advisory database lists none affecting `google.golang.org/grpc` 1.84.0 or `cel.dev/expr` 0.25.2 (both read 2026-11-17).

**Two fixes narrow exposure without patching a reported vulnerability.** A raced gateway can no longer be provisioned onto another tenant's scale-set name by arriving with the GMC finalizer (#2352), and an IPv6 cluster's AGC no longer routes its Kubernetes API traffic through the tenant's egress proxy (#2348).

The `worker`, `build-runner` and `cache-runner` images inherit their upstream base's findings, which CI reports without blocking.
They run `actions/runner` 2.338.2, unchanged from `v2.0.0`, and carry 44, 43 and 43 fixable HIGH or CRITICAL findings, summed per scan target.

A pull request that changes code runs `govulncheck` and a Trivy image scan of every built image, and every push to `main` runs both.
One that changes the chart runs a Polaris posture check of it.
