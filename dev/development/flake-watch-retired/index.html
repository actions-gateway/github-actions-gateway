    Retired flakes¶

    Cold storage for flake-watch rows that have graduated out of the live flake watch table. A row lands here when its recurrence-memory has decayed to ~zero — see the retirement bar in maintaining-backlog.md (soaked — the spec's blast-radius run threshold of green main runs since the fix, or the test/code path is obsolete).

    This ledger exists so retirement is not deletion: it keeps the "a fix was already attempted here" memory grep-able at zero live-table cost. If a retired flake ever recurs, it re-enters the Queue as a fresh find (flakes-first); this row is the pointer back to the original diagnosis, so re-add it to the escalation history rather than starting cold.

    Run counts below are green main runs of the covering workflow since the fix merged, measured with the gh run list recipe in maintaining-backlog.md. Each is anchored on a date at or after the fix, so every count is a conservative undercount.

    A refuted row lands here too, with no fix PR and no soak: the flake it named was never observed, and the record of having looked is worth the same grep. A refuted row that was repurposed rather than retired has no ID left to carry, since another defect holds it.
